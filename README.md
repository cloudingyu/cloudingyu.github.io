# CloudingYu 的博客

使用 Astro 构建的中文技术博客，部署到 GitHub Pages。文章以 Markdown 保存，数学公式由 KaTeX 渲染，代码由 Shiki 高亮；three.js 提供首页的动态立体云。支持明暗主题、静态全文搜索、标签归档与文章分页。文章集合使用编号与大标题组成的开放式列表；正文目录按标题层级缩进，页脚提供联系与友链入口。白日模式的云使用冷色阴影和独立光照配色。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端中显示的地址，通常是 `http://localhost:4321/`。如果依赖文件缺失或安装被中断，重新运行 `npm ci`。

## 构建与检查

```sh
npm run check
npm run build
npm run verify
npm run preview
```

- `check`：同步内容与 KaTeX 字体，然后检查 Astro 和 TypeScript 源码。
- `build`：同步内容与字体，生成可部署的静态网站到 `dist/`。
- `verify`：检查构建产物中的文章、图片、公式、分页、永久链接、搜索与标签数据。需要先构建。
- `preview`：预览 `dist/` 中的静态网站。
- `cloud:bake`：修改 `scripts/bake-cloud.mjs` 中的云形或光照后，重新生成并提交 `src/assets/cloud-volume.bin`。普通构建直接使用这份约 144 KB 的 gzip 素材，无需重新烘焙。

GitHub Actions 按锁文件安装依赖，完成构建、源码检查和内容校验后发布到 Pages。KaTeX 的依赖覆盖让数学插件也使用已修复的同一版本，避免嵌套安装旧版本。

## 内容与目录

| 路径 | 用途 |
| --- | --- |
| `posts/` | 原始文章，是编辑正文与文章元数据的入口 |
| `images/` | 原始图片素材 |
| `SITE_DATA.md` | 站点信息、个人资料、社交链接与页面引语 |
| `POSTS_INDEX.md` | 15 篇文章的原始元数据索引 |
| `src/data/site.ts` | 供页面使用的站点信息 |
| `src/pages/` | 首页、文章、归档、标签、关于、搜索与 404 页面 |
| `src/styles/` | 页面样式与正文排版 |
| `src/scripts/` | 交互、阅读辅助与动态立体云 |
| `scripts/` | 内容同步、KaTeX 字体复制与产物校验 |

`src/content/posts/`、`public/images/`、`public/vendor/` 和 `dist/` 是自动生成的目录，不要直接编辑。`dev`、`check` 和 `build` 会从原始内容重新生成需要的文件。

文章正文、标题、日期和标签保持原样，包括仅有一句话的红黑树文章；文章署名统一为 `CloudingYu`。同步时只转换旧站展示字段、文件扩展名和图片路径，永久链接沿用 `/YYYY/MM/DD/<slug>/`，并保留大小写。

目前有 15 篇文章、17 个标签，首页展示最新 6 篇，独立文章列表使用 `/page/1/`、`/page/2/`、`/page/3/`，每页 6 篇。全站使用统一的实验视觉与共享导航、页脚：巨型排印、酸性绿与紫色配色、动态立体云、开放式文章列表和横向标签流。立体云使用按需加载的 three.js 与体积云着色器，支持鼠标牵引和点击重塑；文章列表支持标题与箭头的悬停动画和滚动入场；首页标题、云、标签与按钮随滚动产生不同速度的移动、缩放与转动。文章、归档、标签、分页、搜索、关于和 404 页面共用这套配色与交互；文章页提供阅读进度和目录；桌面目录向右收成展开按钮，正文随之平滑居中并从最大 56rem 加宽到 64rem，目录在手机端默认折叠；正文上方保留一条分隔线，代码框直接展示代码与行号。列表页共用编号、日期和大标题组成的文章行，归档页按年份排列，搜索页默认只显示大字号输入区；输入关键词后展示匹配结果，清空后恢复空白搜索状态。全站默认采用暗夜配色，保留读者手动选择的明暗主题。没有 WebGL 时用 CSS 图形替代云，阅读链接始终由静态 HTML 提供。系统启用减少动态效果时，立体云显示静态画面，标签可以横向滚动；立体云离开视口或页面隐藏时停止渲染。原始素材中的四张页面背景照片保留在 `images/site/`；构建产物包含 44 张文章配图、头像和 favicon，共 46 个图片文件。

首页整页使用滚动触发的快速入场动画：文章行从左右交错的位置向上滑入，主题标题、标签带、分页和页脚依次显现并缩放。桌面 280 毫秒、手机 240 毫秒完成，即使停止滚动也会迅速恢复清晰原位；进入主要阅读区域后保持稳定。上滑至内容完全离开屏幕后，再次下滑可重播。快速滚动、到达页底或键盘聚焦时立即显示完整内容；减少动态效果模式和没有 JavaScript 时直接显示内容。交互实现在 `src/scripts/home-scroll.js`，只在滚动或布局变化时检查触发位置。

立体云的三种形态共用预烘焙的三维密度与光照素材，浏览器只需采样体积纹理，无需在加载时生成噪声或在每个像素中反复计算云形。素材独立打包并按需下载；鼠标跟随使用 CSS 合成层对已绘制的云做轻微倾斜和位移，不触发 WebGL 重绘，漂浮和滚动也由 CSS 完成。只有换云、主题变化或尺寸变化会重绘体积云，换形动画限制在每秒 30 帧。滚动、离开视口或隐藏页面时暂停绘制，并根据 GPU 耗时调整分辨率，避免云朵拖慢正文交互。

搜索索引随构建生成。搜索页没有 JavaScript 时提供归档入口；索引暂时加载失败时提供重试与归档入口。浏览器不支持 WebGL 时，文章内容与阅读入口仍然可用。系统启用减少动态效果时，立体云显示静态画面。

桌面端的链接、按钮和目录折叠入口共用圆形悬停光标：平时显示空心圆环，指针进入可交互区域时，圆环平滑缩小为 16 像素的实心圆，移开后恢复空心圆环。位置每帧直接跟随鼠标，不再用拖尾缓动。颜色随主题切换，暗夜为绿色、白昼为紫色。触屏及减少动态效果模式沿用原生光标。

主页移除主题标签下方的 BUILD. BREAK. LEARN. 宣言。关于页使用独立的动态个人海报：头像周围的双椭圆轨道、光点与兴趣标签缓慢运动，桌面鼠标在整个介绍区域移动时会牵引头像轨道、光晕和姓名；三个介绍区随鼠标位置产生立体倾斜与跟随光斑，内部轨道、圆环和无限符号产生视差，无限符号的线条也随指针移动；移开或滚动时平滑复位；点击头像（或键盘 Enter / 空格）在 BUILD、BREAK、LEARN 三种灵感状态间切换，伴随短暂粒子与扩散光环。个人介绍使用 AI Infra 探索区、FUDAN 身份色块和好奇心宣言组成的错落拼贴，暗色主题中三个介绍区依次使用淡紫底深色字、绿色底深色字、深紫底暖白字，明色主题依次使用深紫底暖白字、绿色底深色字、淡紫底深色字，支持滚动入场与悬停反馈；移除小号英文标签、编号与装饰性说明，可见说明文字至少 1rem；装饰采用 SVG 线条和几何图形，不使用 emoji，底部 BUILD. BREAK. LEARN. 宣言按可用宽度缩放，手机与桌面始终保持单行，支持悬停填色与星花旋转。手机使用纵向布局，明暗主题沿用站点配色；减少动态效果时保留内容与状态切换，关闭运动。轨道离开视口或页面隐藏时暂停，粒子完成后移除；无 JavaScript 时仍可阅读完整介绍。页面样式与交互分别在 `src/styles/about.css`、`src/scripts/about-effects.js`。

## 学期笔记

双击主页「保持好奇」旁边的句号（手机连续轻点两次），可进入 `/course-note/` 学期笔记；不设置键盘快捷键。笔记区没有普通导航入口，不进入公开文章集合、标签、归档、搜索索引或站点地图，每个页面均带 `noindex`。这是隐藏入口，没有访问控制或加密；知道地址的人可以阅读，仓库中的笔记快照也是公开的。

目前仅导入 2026 年秋季学期的概率论与数理统计、计算理论基础、操作系统（H）、计算机视觉四门课。`notebook/2026-autumn/` 保存独立 Markdown 快照，构建时生成课程列表与每篇笔记的静态阅读页。笔记列表与阅读页以日期为标题，开头的日期和内容分行显示。阅读样式参考 Obsidian 导出的 PDF：霞鹜文楷与 Times New Roman 组合，加粗正文使用黑体字体，Maple Mono 代码字体，1.5 倍行距，以及紧凑的段落、列表、引用和多级标题。沿用网站的明暗颜色，正文初始宽度与博客统一，提供共用的标题目录、阅读进度和当前章节高亮。桌面目录向右收为目录图标，正文同时居中，未自定义宽度时从最大 56rem 加宽到 64rem；手机默认折叠目录，长目录可滚动但隐藏滚动条。标题中的公式保留 KaTeX 排版。博客与课程笔记的正文共用 `src/styles/reading.css`，统一字体、字号、行距与段落格式；访问博客不会下载课程笔记内容。字体仅在正文实际使用时加载。

博客和课程笔记正文支持悬浮球阅读转盘：原顶栏滚出屏幕再下滑 18 像素后，右下角的扁平圆球轻弹入场，伴随一圈细线涟漪；点击球体，四个符号按钮随转盘向左上方旋转展开，不改变阅读位置。按钮提供主页、回到顶部、上一篇和下一篇；缺少相邻文章或笔记时，对应按钮置灰且不可点击。笔记的主页按钮返回学期笔记界面。再次点击球体、点击正文或按 Esc 收起转盘；上滑至原顶栏边界时，圆环轻轻扩散，球体缩小淡出，慢速滚动同样生效。悬停时球心变色并轻微放大、外环转动；鼠标移动和悬停不会展开菜单。手机缩小转盘，右下角入口兼容屏幕安全区域。组件与交互分别在 `src/components/ReadingNavigation.astro`、`src/scripts/reading-navigation.js`，支持键盘操作、明暗主题和减少动态效果。

更新本地笔记后，显式同步，再构建：

```sh
npm run notes:sync -- "你的笔记 Markdown 根目录"
npm run build
```

根目录下应有 `Math/概率论与数理统计`、`Math/计算理论基础`、`CS/操作系统` 和 `CS/计算机视觉`。文件名以 `2026.月.日.md` 结尾；只同步这四个文件夹顶层的 Markdown 文件。同步不修改原笔记，同一日期的快照会更新，原目录中删除的笔记也会从该课程快照移除。提交快照后，GitHub Pages 的构建直接使用它们，不需要读取本地源目录。入口路径和课程配置在 `src/data/notebook-config.mjs` 中维护，路径修改时须同时调整页面路由文件夹名。

`public/fonts/notebook/` 保存文楷与 Maple Mono 的 WOFF2 子集及 OFL 许可；浏览器优先使用已安装的对应字体。子集包含当前博客与笔记使用的字形，未来新增生僻字会使用系统字体补足。需要扩充字形时，在本地安装 `fonttools[woff]`，执行 `python scripts/subset-notebook-fonts.py --font-dir "字体目录"` 后提交更新后的字体文件。字体目录应包含 `LXGWWenKaiMono-Regular.ttf`、`MapleMono-Regular.ttf` 和 `MapleMono-Bold.ttf`，普通构建无需 Python 或原始字体。

博客与课程笔记共用阅读调整功能，调整仅在当前页面生效，刷新或切换页面后恢复默认，不保存或同步阅读设置。正文固定使用默认字号，开头保留随页面滚走的分隔线；悬浮球保持原来的四项导航。目录开关保留在原位置，标题旁不显示进度百分比，页顶进度条和当前章节高亮仍然可用。正文两侧的短直线页边标记可直接拖动调宽，无需展开目录或悬浮球：页边标记跟随当前可见正文定位，目录展开、关闭及中途反向切换时逐帧跟随正文移动，自定义宽度也保持对齐；刷新时也自动显示，正文离开屏幕后隐藏；向外留出间距，默认以 40% 不透明度显示；鼠标靠近或按住拖动时伸展为强调色括线，鼠标离开且结束拖动后恢复竖线，单击不显示外框，键盘聚焦以强调色提示，不叠加正文提示线；双击把手或按 Home 恢复当前博客的默认宽度，左右方向键也可微调。自定义宽度不随目录开关改变，最大 96rem（默认根字号下 1536px），窄屏按可用空间适配。
