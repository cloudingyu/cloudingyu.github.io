# CloudingYu 的博客

使用 Astro 构建的中文技术博客，部署到 GitHub Pages。文章以 Markdown 保存，数学公式由 KaTeX 渲染，代码由 Shiki 高亮；three.js 提供可选的几何场景。支持明暗主题、静态全文搜索、标签归档与文章分页。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端中显示的地址，通常是 `http://localhost:4321/`。如果依赖文件缺失或安装被中断，重新运行 `npm ci`。

## 构建与检查

```sh
npm run check
npm run build
npm run verify
npm run preview
```

- `check`：同步内容与 KaTeX 字体，然后检查 Astro 和 TypeScript 源码。
- `build`：同步内容与字体，生成可部署的静态网站到 `dist/`。
- `verify`：检查构建产物中的文章、图片、公式、分页、永久链接、搜索与标签数据。需要先构建。
- `preview`：预览 `dist/` 中的静态网站。

GitHub Actions 按锁文件安装依赖，完成构建、源码检查和内容校验后发布到 Pages。KaTeX 的依赖覆盖让数学插件也使用已修复的同一版本，避免嵌套安装旧版本。

## 内容与目录

| 路径 | 用途 |
| --- | --- |
| `posts/` | 原始文章，是编辑正文与文章元数据的入口 |
| `images/` | 原始图片素材 |
| `SITE_DATA.md` | 站点信息、个人资料、社交链接与页面引语 |
| `POSTS_INDEX.md` | 15 篇文章的原始元数据索引 |
| `src/data/site.ts` | 供页面使用的站点信息 |
| `src/pages/` | 首页、文章、归档、标签、关于、搜索与 404 页面 |
| `src/styles/` | 页面样式与正文排版 |
| `src/scripts/` | 交互与几何场景 |
| `scripts/` | 内容同步、KaTeX 字体复制与产物校验 |

`src/content/posts/`、`public/images/`、`public/vendor/` 和 `dist/` 是自动生成的目录，不要直接编辑。`dev`、`check` 和 `build` 会从原始内容重新生成需要的文件。

文章正文、标题、日期、标签和署名保持原样，包括小写署名 `cloudingyu` 和仅有一句话的红黑树文章。同步时只转换旧站展示字段、文件扩展名和图片路径，永久链接沿用 `/YYYY/MM/DD/<slug>/`，并保留大小写。

目前有 15 篇文章、17 个标签，首页每页展示 6 篇。首屏左侧展示最新文章的标题、摘要与阅读入口，右侧将真实文章排成有纵深的页面展台，支持逐行标题入场、悬浮光影、鼠标视差与滚动展开。展台可水平拖动换页，也可通过左右按钮或方向键切换；点击当前页面进入文章。首页使用 CSS 3D 和 Web Animations，不加载 WebGL；其他辅助页面保留几何场景。下方文章列表支持鼠标柔光与悬停反馈，侧栏提供常用标签与年份归档；手机上先展示最新文章，分类入口放在列表下方，纵向手势仍用于正常滚动。系统启用减少动态效果时，展台保留静态排版及换页功能；离开视口或后台时暂停持续动画。原始素材中的四张页面背景照片保留在 `images/site/`；构建产物包含 44 张文章配图、头像和 favicon，共 46 个图片文件。

搜索索引随构建生成。没有 JavaScript、搜索索引暂时加载失败或浏览器不支持 WebGL 时，文章内容与阅读入口仍然可用。系统启用减少动态效果时，几何场景显示静态画面。
