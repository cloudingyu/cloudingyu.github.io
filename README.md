# CloudingYu 的博客

使用 Astro 构建的中文技术博客，部署到 GitHub Pages。文章以 Markdown 保存，数学公式由 KaTeX 渲染，代码由 Shiki 高亮；three.js 提供首页的动态立体云。支持明暗主题、静态全文搜索、标签归档与文章分页。文章集合使用编号与大标题组成的开放式列表；正文目录按标题层级缩进，页脚提供联系与友链入口。白日模式的云使用冷色阴影和独立光照配色。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端中显示的地址，通常是 `http://localhost:4321/`。如果依赖文件缺失或安装被中断，重新运行 `npm ci`。

## 构建与检查

```sh
npm run check
npm run build
npm run verify
npm run preview
```

- `check`：同步内容与 KaTeX 字体，然后检查 Astro 和 TypeScript 源码。
- `build`：同步内容与字体，生成可部署的静态网站到 `dist/`。
- `verify`：检查构建产物中的文章、图片、公式、分页、永久链接、搜索与标签数据。需要先构建。
- `preview`：预览 `dist/` 中的静态网站。

GitHub Actions 按锁文件安装依赖，完成构建、源码检查和内容校验后发布到 Pages。KaTeX 的依赖覆盖让数学插件也使用已修复的同一版本，避免嵌套安装旧版本。

## 内容与目录

| 路径 | 用途 |
| --- | --- |
| `posts/` | 原始文章，是编辑正文与文章元数据的入口 |
| `images/` | 原始图片素材 |
| `SITE_DATA.md` | 站点信息、个人资料、社交链接与页面引语 |
| `POSTS_INDEX.md` | 15 篇文章的原始元数据索引 |
| `src/data/site.ts` | 供页面使用的站点信息 |
| `src/pages/` | 首页、文章、归档、标签、关于、搜索与 404 页面 |
| `src/styles/` | 页面样式与正文排版 |
| `src/scripts/` | 交互、阅读辅助与动态立体云 |
| `scripts/` | 内容同步、KaTeX 字体复制与产物校验 |

`src/content/posts/`、`public/images/`、`public/vendor/` 和 `dist/` 是自动生成的目录，不要直接编辑。`dev`、`check` 和 `build` 会从原始内容重新生成需要的文件。

文章正文、标题、日期、标签和署名保持原样，包括小写署名 `cloudingyu` 和仅有一句话的红黑树文章。同步时只转换旧站展示字段、文件扩展名和图片路径，永久链接沿用 `/YYYY/MM/DD/<slug>/`，并保留大小写。

目前有 15 篇文章、17 个标签，首页展示最新 6 篇，独立文章列表使用 `/page/1/`、`/page/2/`、`/page/3/`，每页 6 篇。全站使用统一的实验视觉与共享导航、页脚：巨型排印、酸性绿与紫色配色、动态立体云、开放式文章列表和横向标签流。立体云使用按需加载的 three.js 与体积云着色器，支持鼠标牵引和点击重塑；文章列表支持标题与箭头的悬停动画和滚动入场；首页标题、云、标签与按钮随滚动产生不同速度的移动、缩放与转动。文章、归档、标签、分页、搜索、关于和 404 页面共用这套配色与交互；文章页提供阅读进度和目录，目录在手机端默认折叠；正文上方保留一条分隔线，代码框直接展示代码与行号。列表页共用编号、日期和大标题组成的文章行，归档页按年份排列，搜索页默认只显示大字号输入区；输入关键词后展示匹配结果，清空后恢复空白搜索状态。全站默认采用暗夜配色，保留读者手动选择的明暗主题。没有 WebGL 时用 CSS 图形替代云，阅读链接始终由静态 HTML 提供。系统启用减少动态效果时，立体云显示静态画面，标签可以横向滚动；立体云离开视口或页面隐藏时停止渲染。原始素材中的四张页面背景照片保留在 `images/site/`；构建产物包含 44 张文章配图、头像和 favicon，共 46 个图片文件。

搜索索引随构建生成。搜索页没有 JavaScript 时提供归档入口；索引暂时加载失败时提供重试与归档入口。浏览器不支持 WebGL 时，文章内容与阅读入口仍然可用。系统启用减少动态效果时，立体云显示静态画面。

## 学期笔记

双击主页「保持好奇」旁边的句号（手机连续轻点两次），可进入 `/course-note/` 学期笔记；不设置键盘快捷键。笔记区没有普通导航入口，不进入公开文章集合、标签、归档、搜索索引或站点地图，每个页面均带 `noindex`。这是隐藏入口，没有访问控制或加密；知道地址的人可以阅读，仓库中的笔记快照也是公开的。

目前仅导入 2026 年秋季学期的概统、计算理论基础、操作系统、计算机视觉四门课。`notebook/2026-autumn/` 保存独立 Markdown 快照，构建时生成课程列表与每篇笔记的静态阅读页。笔记列表与阅读页以日期为标题，开头的日期和内容分行显示。阅读样式参考 Obsidian 导出的 PDF：霞鹜文楷与 Times New Roman 组合，加粗正文使用黑体字体，Maple Mono 代码字体，1.5 倍行距，以及紧凑的段落、列表、引用和多级标题。沿用网站的明暗颜色，阅读区域加宽，不显示笔记目录。标题中的公式保留 KaTeX 排版。博客与课程笔记的正文共用 `src/styles/reading.css`，统一字体、字号、行距与段落格式；访问博客不会下载课程笔记内容。字体仅在正文实际使用时加载。

课程还原笔记经过独立的网站知识整理流程后发布，再构建。完整流程见 [网站课程笔记整理项目](course-notes/README.md)，包含 6-luna 写作规范、来源盘点、增量处理、独立复核、发布及当前仓库提交。

```sh
npm run notes:inventory
npm run notes:prepare -- --note probability/2026-09-30
# 完成草稿整理与独立复核后：
npm run notes:validate -- --note probability/2026-09-30
npm run notes:publish -- --note probability/2026-09-30
npm run build
```

来源路径配置在被 Git 忽略的 `course-notes/local.config.json`，示例见同目录 `config.example.json`。原笔记根目录应有 `Math/概率论与数理统计`、`Math/计算理论基础`、`CS/操作系统` 和 `CS/计算机视觉`，文件名以 `2026.月.日.md` 结尾。原笔记和 OnlineCourses 资料只读，每篇审核通过后更新对应网站快照、公开核查记录和来源清单，提交到本仓库。来源删除只标记缺失，不自动删除页面。`notes:sync -- --note <课程ID/YYYY-MM-DD>` 是发布别名，旧的原目录整批同步调用已停止使用。

当前 20 篇旧快照均登记为待整理；项目搭建不代表内容已完成转换。check/build 校验已发布整理成果，CI 直接读取仓库文件，不访问本地原件。入口路径和课程配置在 `src/data/notebook-config.mjs` 中维护，路径修改时须同时调整页面路由文件夹名。

`public/fonts/notebook/` 保存文楷与 Maple Mono 的 WOFF2 子集及 OFL 许可；浏览器优先使用已安装的对应字体。子集包含当前博客与笔记使用的字形，未来新增生僻字会使用系统字体补足。需要扩充字形时，在本地安装 `fonttools[woff]`，执行 `python scripts/subset-notebook-fonts.py --font-dir "字体目录"` 后提交更新后的字体文件。字体目录应包含 `LXGWWenKaiMono-Regular.ttf`、`MapleMono-Regular.ttf` 和 `MapleMono-Bold.ttf`，普通构建无需 Python 或原始字体。
