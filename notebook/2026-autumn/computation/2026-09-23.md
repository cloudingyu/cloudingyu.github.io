## 一、复课：有限自动机的定义与接受 [00:02:00–00:11:53]

### 1.1 本次课的起点与有限自动机的定位

老师先回顾上节课：已经讲完了**有限自动机**（finite automaton, FA）的定义，也做了一些有限自动机的例子和编程。

这门课的第一部分是要定义一个计算模型，而且是用数学的方式定义。我们首先定义的是一个受限的计算模型，或者说是一个没有内存的计算机；更严格地说，是一个没有无限内存的计算机。

> **老师强调**：为什么要说“无限内存”？因为有些自动机我们也可以用状态进行记忆，但是状态是有限的，所以我们只能记住有限的信息。

**课堂问答**：老师接连提出两个问题，并自己回答。

1. 我们用的这台计算机，它是不是一个有限状态自动机？老师回答：是的。因为它有 32G 或者 64G 的内存，然后还有一些硬盘，那它所有可能的状态数就是 2 的那么多次方，是有限的。
2. 人的大脑是不是一个有限自动机？老师回答：很可能是。有数百亿的神经元，每个神经元又有一些有限的状态，那状态的总数是有限的。但是我们不会用有限自动机对它进行建模，因为状态数实在是太大了，它不是一个有效的建模方式。

所以我们学习有限自动机，一方面是为了引出这门课的主角——图灵机（Turing machine）；另外一方面，也是从一个玩具模型开始研究它的可计算性：哪些问题可以被有限自动机识别、哪些不可以；同时为后面学习更大更复杂的复杂性类（像 P、NP 之类）积累经验、做一些准备。

老师补充：图灵机的定义跟这个有限自动机的定义非常像，只差一点点——加上那一点点功能，我们就能得到一个图灵完备（Turing-complete）的机器。

### 1.2 五元组定义与“只读一遍”的等价性

**定义**：有限自动机是一个五元组
$$M=(Q,\Sigma,\delta,q_0,F),$$
其中 $Q$ 是有限的状态集（states）；$\Sigma$ 是字母表（alphabet），就是一些有限的字符的集合；$\delta$ 描述这个有限自动机的转移逻辑，由当前的状态还有读到的这个字符转移进入下一个状态；$q_0\in Q$ 是初始状态（start state）；$F\subseteq Q$ 是接收状态（accept states）的集合。

这个有限自动机是从左读到右的，每次读一个字符。也不难证明：如果你允许它读两遍、读三遍，其实和这个还是等价的——就是说你允许它从左读到右、再从右读到左，或者再读一遍，甚至来回地读，但是不允许写、不允许改写，这样你得到的还是可以把它转换成一个等价的“每次读一个、往右走”的有限自动机。

什么算是接收呢？当这个机器读到最后一个字符，如果是停留在一个接收状态就是接收，如果停留在其他状态就是拒绝。这里我们只考虑判定问题，就是它的输出、它的答案就是 yes 或者 no。

老师又回顾了上节课讲过的两个例子。老师讲到“之前我们看到一个（二进制数是不是）2 的倍数的这个例子……这里可以画一张表，就是用一张表去描述这个转移函数 $\delta$”，并说“类似的我们另外一个看过的例子，一个二进制数是不是 3 的倍数，然后也可以用一张表来描述这个转移函数”。这两台自动机的转移函数写成转移表就是：

| 被 2 整除的自动机（$\Sigma=\{0,1\}$，$Q=\{q_0,q_1\}$，$F=\{q_0\}$） | 读入 $0$ | 读入 $1$ |
|---|---|---|
| $q_0$ | $q_0$ | $q_1$ |
| $q_1$ | $q_0$ | $q_1$ |

| 被 3 整除的自动机（$\Sigma=\{0,1\}$，$Q=\{q_0,q_1,q_2\}$，$F=\{q_0\}$） | 读入 $0$ | 读入 $1$ |
|---|---|---|
| $q_0$ | $q_0$ | $q_1$ |
| $q_1$ | $q_2$ | $q_0$ |
| $q_2$ | $q_1$ | $q_2$ |

这两个例子在上节课已经完整讲过，本次只是回顾，所以这里不再展开它们的构造过程。

### 1.3 形式化：什么叫做有限自动机接收一个输入

这门课都是关于形式化的，我们会严格定义所有的事情。那什么叫做有限自动机接收一个输入、接收一个字符串？这也要定义一下。

**定义**：设 $M=(Q,\Sigma,\delta,q_0,F)$ 是一个有限自动机，$w=w_1w_2\cdots w_n$ 是一个长度为 $n$ 的字符串。我们说 $M$ **接受**（accept）$w$，当且仅当存在一个状态序列
$$r_0,r_1,\dots,r_n\in Q,$$
使得：

1. $r_0=q_0$（序列从初始状态出发）；
2. 对 $i=0,1,\dots,n-1$，$\delta(r_i,w_{i+1})=r_{i+1}$。因为它是一个**确定性有限自动机**（Deterministic Finite Automaton, DFA），$r_i$ 和读到的字符 $w_{i+1}$ 唯一确定了下一个状态，也就是说 $r_{i+1}$ 由转移函数 $\delta$ 给出；
3. $r_n\in F$——因为要接收这个输入，所以最后必须落在一个接收状态。

老师补了一句：有同学问“老师，这还要定义吗？”——还要的。数学就是关于形式化的。这个定义“跟你想的一样，就是你想的那个”，我们什么也没做，我们只是把这个定义写下来。

### 1.4 形式化：有限自动机识别的语言

**定义**：$M$ 是一个有限自动机，“$M$ 识别（recognize）或者接受（accept）的这个语言”是什么呢？就是所有那些它接收的字符串构成的集合
$$L(M)=\{\,w\in\Sigma^*: M\text{ 接受 } w\,\}.$$
这个集合叫做它接收的语言，或者它识别的语言。若 $L(M)=L$，我们称 $M$ 识别 $L$，或 $M$ 接受 $L$。

每一个有限自动机都识别一个语言。那反过来不一定——不是说每个语言都可以有一个有限自动机来识别。

如果这个自动机什么也不接收，那它还是识别了一个语言，这个语言就是空语言，就是空集。空集也是一个语言，因为语言就是字符串的集合。所以如果这个机器什么都不接收，那它仍然识别一个语言，就是 $\varnothing$。

## 二、正则语言的定义、语言层次与实例 [00:11:54–00:26:04]

### 2.1 正则语言的定义

**定义**：那这类“能被有限自动机识别的语言”叫做什么呢？叫做**正则语言**（regular language）。一个语言叫做正则语言，当且仅当存在一个有限自动机识别它：
$$L\text{ 是正则语言}\iff \exists\,M\text{（有限自动机）},\ L(M)=L.$$
英文是 regular languages。

所以如果有一个有限自动机能识别它，它就是正则语言；如果不存在这样的有限自动机，那它就不是正则语言。

### 2.2 语言层次图：所有语言中的正则语言

老师用一张语言层次图帮我们看清正则语言所处的位置。他画的是一张四层嵌套的图：最外面最大的一个圈是 All Languages（所有语言）；往里一层是“可以被计算的语言”，这张图把这一层写作 Decidable Languages，也就是**可判定语言**；再往里是 $\mathrm{P}$；最里面最小的那个圈是 Regular（正则语言）。他随后逐层说明每一层的含义。

1. 最外面最大的圈就是所有的语言。我们有不可数个语言：因为所有字符串构成的集合是可数的，所以所有的语言就是 $2^{\aleph_0}$（老师口述为“二的阿列夫零”），也就是 $2^{\aleph_0}$ 这么多，是不可数的。
2. 中间这个圈是所有的那些可以被计算的语言。但是我们现在还没有定义计算机，还没有图灵机的定义，所以这一层目前只是一个待定义的圈。
3. $\mathrm{P}$ 是那些可以在多项式时间内被判定的语言。
4. 最小的这个圈就是正则语言。这是一个非常小的复杂性类，因为自动机是一个受限制的计算模型，是一个玩具模型。

所以我们这节课学习、研究的就是这个最小的圈，研究这个语言的一些性质。什么性质呢？就是它的一些**闭包性质**（closure properties）：对于这个最小的复杂性类，我们研究哪些语言在里面、哪些不在里面；怎么样证明一个语言不是正则的；怎么样描述一个正则语言（后面会讲正则表达式）。

> **老师强调**：一方面我们研究有限自动机是为了导出这门课的主角图灵机，因为它们非常像，只是增加了一点点的功能，我们就得到了一个强大的计算机；另外一方面我们希望研究这个小的复杂性类，对于我们研究更大的那些复杂性类有所启示。

老师同时预告：我们还会研究一下正则表达式，也就是怎么描述一个正则语言。一方面正则表达式挺有用的：大家写一些 Linux 或者 Windows 指令——像 `grep` 这些——就可以写正则表达式；如果大家学编译原理，写一些 parser（语法分析器）也需要一些语言方面的支持。另外一方面我们学习正则语言是为了给我们带来一些启示，去学习一些更大的复杂性类，像 P、像 NP 这些。

> **原文待核实**：老师口中“像 `rejects` 这些”指的是哪个指令，原文待核实（时间约 00:29:49–00:29:52）；结合上下文（“写一些 Linux 或者 Windows 指令”“可以写正则表达式”）应指 `grep`，同一段落后文也明确提到 `grep`。

### 2.3 例子一：所有以 1 结尾的字符串

**例子**：所有的以 1 结尾的字符串构成的语言
$$L_1=\{\,w\in\{0,1\}^*: w\text{ 以 }1\text{ 结尾}\,\}$$
是一个正则语言。

为什么要证明一个语言是正则的？只要证明存在一个有限自动机识别它就可以了（这正是正则语言的定义）。我们可以构造这样一个有限自动机：它有两个状态 $q_0,q_1$，其中 $q_0$ 表示“当前读到的字符串的最后一位是 0”，$q_1$ 表示“最后一位是 1”。

- 在 $q_0$ 读到一个 0 就停留在 $q_0$；
- 在 $q_0$ 读到一个 1 就转移到 $q_1$；
- 在 $q_1$ 读到一个 0 回到 $q_0$，读到一个 1 仍停留在 $q_1$。

上面这台自动机的初始状态是 $q_0$，接收状态集是 $F=\{q_1\}$。如果最后那个符号读完之后停留在 $q_1$，那就接收它。把它的转移函数写成转移表就是：

| 状态 | 读入 $0$ | 读入 $1$ |
|---|---|---|
| $q_0$ | $q_0$ | $q_1$ |
| $q_1$ | $q_0$ | $q_1$ |

### 2.4 例子二：第一位和最后一位不同

**例子**：设 $w=w_1w_2\cdots w_n$，考虑
$$L_2=\{\,w\in\{0,1\}^*: n\ge2,\ w_1\ne w_n\,\},$$
也就是所有第一位和最后一位不同的字符串构成的语言，其中 $n\ge2$ 说明长度为 0 或 1 的字符串都不在这个语言里（它们没有“第一位和最后一位不同”这一说）。我们要问：怎么识别这个语言呢？

因为有些自动机虽然没有内存，但是我们可以用状态进行记忆，我们可以记有限的、有限的事情。所以我们读到 $w_1$ 的时候可以分叉：如果 $w_1$ 是 0，我们就走上面一个分支；如果 $w_1$ 是 1，我们就走下面一个分支。然后在第一个分支里，我们来看 $w_n$ 是等于 0 还是一；在第二个分支里，看 $w_n$ 是等于 1 还是 0。也就是说，我们可以不停地把状态分开、去记住有限的信息。

如果读到的 $w_1$ 是 0 就走上面：最后 $w_n$ 是 1 我们就接收，$w_n$ 是 0 我们就不接收（因为 $w_1=w_n$，此时不需要接收；这个分支后续无论读到什么都只能自环，是一个死状态）。如果 $w_1$ 是 1 就走下面：如果 $w_n$ 是 0 我们接收；如果 $w_n$ 是 1 的话我们就拒绝。所以这个语言还是正则语言，我们可以设计这样一个有限自动机去识别它。老师评价：“相信大家也都能做出来。”

这台自动机一共有 5 个状态 $q_0\sim q_4$，起点是 $q_0$，接收状态是 $q_3,q_4$。它的工作方式是：起点 $q_0$ 先记住首位字符，读到 0 就进入“首位是 0”的那条分支，读到 1 就进入“首位是 1”的那条分支；在“首位是 0”的分支里，只有最后一位读到 1 时停在接收状态 $q_3$，最后一位读到 0 时落在拒绝状态；在“首位是 1”的分支里，只有最后一位读到 0 时停在接收状态 $q_4$，最后一位读到 1 时落在拒绝状态。两条分支中各有若干中间状态用来“记住已经读过了首位”，这些中间状态都落在 $q_1,q_2$ 这两个拒绝状态上。

把它的转移函数 $\delta$ 完整写出来，就是下面这张转移表（$q_0$ 是初始状态，$q_3$、$q_4$ 是接收状态）：

| 状态 | 读入 $0$ | 读入 $1$ |
|---|---|---|
| $q_0$ | $q_1$ | $q_2$ |
| $q_1$ | $q_1$ | $q_3$ |
| $q_2$ | $q_4$ | $q_2$ |
| $q_3$ | $q_1$ | $q_3$ |
| $q_4$ | $q_4$ | $q_2$ |

这张表把每个状态的含义写得很清楚：$q_1$ 表示“首位是 0、当前读到的最后一位也是 0”，$q_3$ 表示“首位是 0、最后一位是 1”；$q_2$ 表示“首位是 1、最后一位是 1”，$q_4$ 表示“首位是 1、最后一位是 0”。$q_3$ 与 $q_4$ 正好对应“首位与末位不同”的两种情形，所以它们是接收状态；$q_1$ 与 $q_2$ 是拒绝状态，分别对应“首位与末位相同”的两种情形。读完全部字符后停在 $q_3$ 或 $q_4$，就说明首位和末位不同，这正是 $L_2$ 要求的。这些状态编号与箭头是按本节课件《lec5_slides_regular_languages.pdf》第 6 张幻灯片核对后写出的；课堂口述只讲了“分两支、各自记住首位、最后看末位”的思路。

### 2.6 课堂练习一：五个语言是否正则

**例题**：判断下列五个语言是否为正则语言。

**题目**：判断下面每个语言是不是正则的。老师说明：如果它是正则的，就存在一个有限自动机；如果它不是正则，我们稍后会讲到（泵引理）——所以大家只要做一个判断就可以了。

1. $L_1=\{\,w\in\{0,1\}^*: w\text{ 含有 }001\text{ 作为子串}\,\}$（contains $001$ as a substring）；
2. $L_2=\{\,w\in\{0,1\}^*: w\text{ 不含有 }001\text{ 作为子串}\,\}$（does not contain $001$ as a substring）；
3. $L_3=\{0^n1^n: n\ge0\}$；
4. $L_4=\{\,w\in\{0,1\}^*: w\text{ 中 0 的个数和 1 的个数相等}\,\}$（$w$ has an equal number of 0's and 1's）；
5. $L_5=\{0^n1^m: n,m\ge0\}$。

**解答**：下面是老师公布的答案与理由，以及按老师课上给的思路补出的完整构造。

1. **是正则的**。老师给的思路是用状态来记录：用八个状态记住目前读到的最后三个字符，所有可能共八种状态（$2^3=8$），这样就能记住“前面的三个字符是不是 $001$”。把这八个状态写成三元组 $(a,b,c)$（表示最近读到的三个字符），读入新字符 $d$ 就转移到 $(b,c,d)$；再把状态 $001$ 设为接收状态、并让它对 $0$、$1$ 都自环（也就是一旦出现过 $001$ 就永远接收）。字符串开头不足三个字符的位置可以先用特殊标记补齐，这样这台机器识别的正是“含有 $001$ 作为子串”的语言。
2. **也是正则的**，也是可以做的。同样记录当前读到的字符和前三个字符构成的、所有 8 种可能的状态；如果读到这样一个子串（$001$）就拒绝——这其实是第一题那台机器的补机器，把接收状态翻过来即可（把遇到 $001$ 的那个状态由接收改为拒绝，并让它自环）。老师补充说：因为“正则语言的补也是正则的”这条闭包性质我们马上要证明（见 3.2），所以第一题答案为“正则”之后，第二题也就跟着是正则的。
3. **不是正则的**。因为有些（有限）状态自动机它没有办法记录有多少个 0、多少个 1；然后它也没有办法来回地读、擦除，来做这样的一个操作。老师在这里预告：我们稍后会看一个工具叫 pumping lemma，叫泵、水泵，那个“泵水”的“泵”定理——它提供一个方法，可以证明某个语言它不是正则语言。（本次练习只要求判断；它的正式证明见 9.5 第 1 题。）
4. **不是正则的**。因为“0 的个数和 1 的个数相等”这个语言也不是正则的。（正式证明同样见 9.5 第 2 题。）
5. **是正则的**。就是若干个 0 后面接很多个 1：$0^n1^m$ 这样的形式，画一条“读完 0 之后读到 1 就再也不能读到 0”的两段式自动机即可。具体地：状态 $q_0$（初始状态，同时是接收状态，对应空串或只读到 0 的情形）、$q_1$（接收状态，对应已经读到 1 的情形）、$q_2$（拒绝的死状态）；转移为 $q_0\xrightarrow{0}q_0$、$q_0\xrightarrow{1}q_1$、$q_1\xrightarrow{1}q_1$、$q_1\xrightarrow{0}q_2$，并且 $q_2$ 对 $0$、$1$ 都自环（一旦读到 0 后面的 0 就永远拒绝）。接收状态集是 $F=\{q_0,q_1\}$。

## 三、正则语言的闭包性质（上）：补、并、交、差 [00:26:04–00:39:07]

### 3.1 闭包性质的总体陈述与语言运算回顾

这节课我们证明这样一个结论：**正则语言满足闭包性质**。那什么是闭包性质？就是一些集合操作。如果 $A$ 是正则语言、$B$ 是正则语言，那它们的补也是正则的；它们的并也是正则语言；交也是正则语言；连接也是正则语言；然后星（Kleene 星）也是正则语言。

老师说，这也是我们接下来大概 1 个小时要做的事情。

我们回忆一下这些集合操作。比如说
$$A=\{0^i: i\ge0\}=\{\epsilon,0,00,000,\dots\}$$
是连续个 0 构成的集合（语言），包括空串；而
$$B=\{1^j: j\ge0\}=\{\epsilon,1,11,111,\dots\}$$
是连续个 1 构成的集合（语言）。那么：

- $A\circ B=\{0^i1^j: i,j\ge0\}$，就是若干个 0 后面跟着若干个 1；
- $A^*=A$——A 的星就是我们在集合 A 中任取若干个字符串然后连接起来；因为 $A$ 里每个元素本身就是一串 0，取若干个拼起来还是一串 0，所以 $A^*=A$；
- 同理 $B^*=B$；
- $(A\circ B)^*=\{0,1\}^*$——因为 $A\circ B$ 这个集合里面已经有 $\epsilon$、有 0、有 1，还有很多其他的字符串（它已经包含了 $01$ 等等），把它整体星一下，就得到所有的字符串，也就是 $\{0,1\}^*$。

**定义**：语言的运算（本节要用到的五条），设 $A,B$ 是语言：

- **补**（complement）：$\overline A=\{\,x\in\Sigma^*: x\notin A\,\}$；
- **并**（union）：$A\cup B=\{\,x: x\in A\text{ 或 }x\in B\,\}$；
- **交**（intersection）：$A\cap B=\{\,x: x\in A\text{ 且 }x\in B\,\}$；
- **连接**（concatenation）：$A\circ B=\{\,xy: x\in A,\ y\in B\,\}$；
- **星**（star）：$A^*=\{\,x_1x_2\cdots x_k: k\ge0,\ \text{每个 } x_i\in A\,\}$。

老师说明本节证明的组织方式：我们下面 40 分钟就去证明这样一个结论——正则语言对于这些集合的操作都是封闭的，就是都是正则的。

### 3.2 补运算封闭

**定理**：若 $L$ 是正则语言，则它的补 $\overline L$ 也是正则的。

**证明**：如果 $L$ 是一个正则语言，那么就有一个 DFA 去识别它，记为 $M=(Q,\Sigma,\delta,q_0,F)$。那我们就构造另外一个 DFA 去识别它的补，这个 DFA 和 $M$ 几乎是一样的，唯一的区别就是把那个状态（的接收与否）给翻过来：
$$M'=(Q,\Sigma,\delta,q_0,F'),\qquad F'=Q\setminus F.$$
也就是如果原来是接收状态我们就（把它）变成拒绝，如果原来是一个拒绝状态我们就（把它）变成接收。这样 $M'$ 恰好接收 $M$ 所拒绝的那些字符串，所以 $L(M')=\overline L$。然后我们根据正则语言的定义——“一个语言是正则的当且仅当有一个 DFA 去识别它”——就证明了 $\overline L$ 也是正则的。

老师补充：那如果再补一次就回到它自身了，就是它的补的补就是它自己，$\overline{\overline L}=L$。

老师问“这个证明大家有问题吗？”随后确认“非常好”。

### 3.3 并运算封闭：同时跑两台机器

**定理**：如果 $L_1,L_2$ 是正则语言，那么它们的并 $L_1\cup L_2$ 也是正则的。

**证明**（思路）：这个怎么处理呢？有限状态自动机就是我们有限的状态数，多少不要紧，只要是有限的就可以。所以我们可以同时跑这两个机器，然后接收（的判定是）只要有一个接受就可以了。

那我们怎么样同时跑这两个机器呢？可以用那个**笛卡尔积**（Cartesian product）。比如说 $L_1$（的机器）有 $P$ 个状态，$L_2$（的机器）有 $Q$ 个状态，那我们就用笛卡尔积构造一个更大的、有 $P\times Q$ 个状态的有限自动机，然后去同时地跑这两个机器。用第一个分量：状态就是比如说 $(r,r')$ 构成的一个对（pair），其中 $r$ 记录的是 $L_1$ 那台机器的状态，$r'$ 记录的是 $L_2$ 那台机器的状态。

当然，数学都是关于形式化的，我们要形式地把它写出来。我们（先给出）$M_1$ 是一个识别 $L_1$ 的有限自动机：
$$M_1=(Q_1,\Sigma,\delta_1,q_1,F_1),\qquad M_2=(Q_2,\Sigma,\delta_2,q_2,F_2),\quad L(M_2)=L_2.$$

然后我们构造一个更大的 DFA $M=(Q,\Sigma,\delta,q_0,F)$ 去识别 $L_1\cup L_2$。怎么构造呢？

1. $Q=Q_1\times Q_2$，这里是笛卡尔积；也就是说 $Q$ 的状态是一个二元组 $(r_1,r_2)$，其中 $r_1\in Q_1$、$r_2\in Q_2$；
2. $\Sigma$ 是一样的，字母表没变，与 $M_1$、$M_2$ 相同；
3. $\delta\bigl((r_1,r_2),a\bigr)=\bigl(\delta_1(r_1,a),\ \delta_2(r_2,a)\bigr)$。因为它是一个二元组，所以 $\delta$ 这样作用在 $r_1$ 和 $r_2$ 上：用 $\delta_1$ 作用在第一个分量、用 $\delta_2$ 作用在第二个分量；也就是这个大的转移函数忠实地模拟这两个小的转移函数，作用在每个分量上；
4. $q_0=(q_1,q_2)$，就是分别两个分量都是初始状态；
5. $F=\{\,(r_1,r_2): r_1\in F_1\text{ 或 }r_2\in F_2\,\}$。

接收状态就是只要有一个分量是接收状态就接收，因为我们想识别的是 $L_1\cup L_2$——就是这个字符串如果在 $L_1$ 里面或者在 $L_2$ 里面，我们就接受了。所以通过这个笛卡尔积的构造方式，就可以同时地去模拟这两个 DFA。老师问“这个证明大家可以理解吗？如果不可以理解的同学举一下手”，随后说“非常好，都理解了”。

老师在写 $M_1$、$M_2$ 的记号时特意提醒：这里下标是一，那边下标都是一；这边下标是 2，那边下标都是 2。“老师是故意这么选的。”
> **老师强调**：我之前的导师有跟我说过，他说如果你对记号非常小心……他对记号一直很挑剔。他做一个证明，他会纠结很久：这个是下标一还是 2，还是 A 还是 B，还是用大写还是小写，还是用那个希腊字母 $\alpha$、$\beta$、$\gamma$ 这些。为什么要这么计较呢？他跟我说，就是说你这个记号选对了，你证明的 70% 就结束了。所以好的数学家一般对记号、对怎么去呈现它是非常挑剔的。
> >
> > **老师比喻**：就像我们用的那个微积分的记号，牛顿、莱布尼茨——他们就是独立的（各自）发现这个微积分，但是我们用的这一套记号应该是莱布尼茨的。

### 3.4 交运算封闭与差运算

**定理**：如果 $L_1,L_2$ 是正则语言，那么 $L_1\cap L_2$ 也是正则的。

**证明**：$L_1\cap L_2$ 是一样、一模一样的构造，还是笛卡尔积；唯一的区别就是接收状态那里，把 or 改成 and：$F=\{\,(r_1,r_2): r_1\in F_1\text{ 且 }r_2\in F_2\,\}$，也就是这两个分量都是接收状态我们才接收。这样我们就得到了这个交，$L(M)=L_1\cap L_2$。

老师说，此外还有集合里面的（运算），比如“对称差（symmetric difference）”，以及用第一个集合减去第二个集合的集合差（set minus），也是类似的。

**推导**：这些没有单独写出构造的运算，其实都可以由已经证明的四条性质凑出来。

1. 第一步，把集合差改写成补与交：$L_1-L_2=L_1\cap\overline{L_2}$——先用补运算把 $L_2$ 变成 $\overline{L_2}$；
2. 第二步，再用刚才那个笛卡尔积构造（接收状态取“且”）对 $L_1$ 和 $\overline{L_2}$ 求交，得到的语言就是 $L_1-L_2$，所以 $L_1-L_2$ 是正则的；
3. 第三步，对称差同理，它是 $(L_1-L_2)\cup(L_2-L_1)$，由前两步已知 $L_1-L_2$ 与 $L_2-L_1$ 都是正则的，再取并仍然正则。

所以这些没有单独写构造的运算也都是正则语言。

## 四、非确定性有限自动机的引入：动机、直观与练习 [00:39:09–00:49:14]、[00:57:00–01:11:06]

### 4.1 连接运算的障碍：不知道该在哪里断开

**定理**：如果 $L_1,L_2$ 是正则语言，我们想证明 $L_1\circ L_2$ 也是正则的。

如果（我们手里）是图灵机、是 C 语言、是 Python，你可以写一个 loop，写一个 for 循环，去枚举一下在哪里把这个字符串断开，然后把第一个子串丢给一个程序、把第二个子串丢给第二个函数。但是问题在于，我们在这个有限自动机里面不知道、就是没有办法写这个 for loop：我们不知道这个字符串在哪里把它分开来，把它一分为二，然后把第一部分丢给第一个机器、把第二部分丢给第二个机器。问题就在于我们不知道在哪里把它给切开来。

当然硬来也是可以的——如果你用 DFA 去证明这个结论也是可以的，但是会有点费劲。

所以这里需要的那个想法是：我们很想在这个字符串的某个位置把它切成两段，让第一个自动机去检查前半段、第二个自动机去检查后半段，但我们又不知道切在哪里。于是我们引入一个新的概念，叫**非确定性有限自动机**（Nondeterministic Finite Automaton, NFA）——它就是用来解决“不知道该在哪里断开”这个障碍的（课件第 15 张）。

### 4.2 为什么要引入一个“不存在”的模型

为什么引入这样的一个新的模型呢？首先，这个模型是不存在的，它是一个完全概念性的模型——就是在现实之中，我们之后也会定义非确定性图灵机（nondeterministic Turing machine），就是非确定的，它不存在、不存在这件事情。但是它是一个概念性的模型。

一方面它会帮我们简化我们的证明；而且引入这样一个不存在的概念模型也是大有裨益。$\mathrm{NP}$ 就是这样定义的。$\mathrm{NP}$ 是什么？$\mathrm{NP}$ 不是 not P，$\mathrm{NP}$ 是“非确定性（图灵机）多项式时间内可解的”——它是非确定性的图灵机在多项式时间内可解的那些语言。

> **原文待核实**：老师口述 NP 的全称时 ASR 记为“nanometer phenomenon”，按上下文与标准术语应为 **nondeterministic polynomial time**（非确定性多项式时间）；时间约 00:41:30–00:41:36。

所以有的时候在数学里面，我们引入一些完全不存在的一些概念是很有好处的。就像那个虚数，就是 $\mathrm{i}$ 的平方等于负一——其实不存在的，不存在这样的一个实数它的平方等于负一。但也是（有一位）我们国家的数学家（说过）：复数的存在对于数学来说就是一个奇迹。就是说复数里面有很多结论是非常美的，就好比一个复数域上一个 $n$ 次的方程就正好有 $n$ 个根、正好有 $n$ 个根。所以很多时候我们引入一些概念性的定义、概念性的模型，这个是大有裨益。

> **原文待核实**：老师说“我们国家一个数学家”时，ASR 记为“陈醒生”；按上下文（关于复数存在性的评价）应为数学家**陈省身**（Shiing-Shen Chern），但录音中的具体人名与这句话的原始出处均待核实；时间约 00:42:04–00:42:08。

老师也问过 AI：你有没有办法提出一些重要的一些概念？AI 说它不可以，它没有这样的能力。AI 虽然善于计算，但是需要人的这种判断（judgment）去提出哪些概念是重要的。这里就是一个例子：就是引入了一个概念叫做非确定性的计算（nondeterministic computation），就像引入虚数 $\mathrm{i}$（$\mathrm{i}^2=-1$）一样，都是很重要的概念。这些概念非常重要，因为它们可以用来推理、用来简化证明、用来揭示结构。AI 系统可以帮我们把已有的概念讲清楚、可以做一些反复的计算，但是它没有这样的能力去识别出哪个新概念是真正重要、值得被定义的。

所以我们为了证明定理五（Theorem 5，连接的闭包性），我们定义一个新的模型，叫做 NFA，非确定性的有限自动机。

### 4.4 NFA 的直观：非确定性与 ε-转移

那什么是非确定性有限自动机呢？

在 DFA 里面，下一个状态它是确定的、它是唯一确定的：由当前状态和输入字符能够确定下一个状态。但是在 NFA 里面它不确定——你可以转移到一个状态 $q_1$，又可以转移到状态 $q_3$，它可能会进行分支。那它取哪一个呢？是不是抛硬币呢？不是的。抛硬币的话你得到的是概率式的（probabilistic），你可以定义比如说概率式的有限自动机，每次你面临一个选择的时候你都抛硬币。

它不是抛硬币，那它怎么做？——平行宇宙。就好比老师当时在这里读书的时候，当时面临两个选择，是留在大陆工作还是出国读书，最后只能做一个选择，就去出国读书了；但是如果是平行宇宙的话，你可以同时（都选）。或者说它的直觉极好：就是每一次面临一个选择，它猜都猜对，每次猜都是对的，然后它总是能够找到这个接收状态。

所以 NFA 接收一个字符串，当且仅当存在这样的一个选择、存在这样的计算路径，它可以导致一个接收状态。所以在现实中是造不出这样的机器的。你说为什么它可以同时、同时做（多个选择）。

老师随后举了 NFA 的具体例子：首先它会有一种转移叫 $\epsilon$-转移（epsilon transition / ε-箭头）。为什么是 $\epsilon$ 呢？就是它什么都没读到，它也可以转移，就是 $q_0$ 可以直接跳到 $q_1$，或者 $q_0$ 可以直接跳到 $q_3$；也可以不跳。也就是说我们什么都没读，我们可以留在 $q_0$，也可以跳到 $q_1$，也可以跳到 $q_3$——$\epsilon$-转移就是一次空转移，你可以转移也可以不转移。

那这个自动机它识别的是什么呢？它可能会跳到上面（那个分支）：跳到上面之后在那里绕圈，绕圈最后读到一个 1，那就是那些**以 1 为结尾**的字符串；或者它可能跳到下面（那个分支）：跳到下面绕一些圈，然后读到 $01$，然后再绕圈，那就是那些**包含 01 作为子串**的字符串。所以这个自动机识别的是：以 1 作为结尾的字符串，或者那些包含 01 作为子串的字符串。

所以大家也可以看出来，这个 NFA 更强大：就是它可以不确定地去转移，然后还可以进行这个空转移，是一个看似更强大的一个模型。

老师举的这台 NFA 的状态是 $q_0,q_1,\dots,q_5$，起点是 $q_0$，接收状态是 $q_2$ 和 $q_5$。从 $q_0$ 出发有两条 $\epsilon$-箭头，分别到 $q_1$ 和 $q_3$——所以它一开始不需要读任何字符，就可以同时（非确定地）进入这两条分支。上分支：$q_1$ 在 $0$、$1$ 上都有自环（也就是读什么都留在 $q_1$），一旦读到 $1$ 还可以转移到 $q_2$，而 $q_2$ 是接收状态——这条分支负责“以 $1$ 结尾”。下分支：$q_3$ 在 $0$、$1$ 上都有自环，读到 $0$ 转移到 $q_4$，$q_4$ 读到 $1$ 转移到 $q_5$，$q_5$ 是接收状态——这条分支负责“含有子串 $01$”。$q_2$ 上没有走出别的状态的箭头（读到下一个字符时这一支就结束了），$q_5$ 则在 $0,1$ 上自环（进去以后读什么都留在 $q_5$）。所以这台 NFA 识别的语言就是：以 $1$ 结尾的字符串，或者含有子串 $01$ 的字符串。注意 $q_0$ 本身没有读到 $0$ 或 $1$ 的转移，它只负责用两条 $\epsilon$-箭头把计算“分叉”出去。

两边的差别可以归成三点。第一，在 DFA 里，下一个状态由当前状态和输入字符唯一确定；第二，在 NFA 里，下一个状态可能有多个选择，不必唯一；第三，NFA 接收一个字符串，当且仅当存在某一串（某一系列）选择，使它最终到达一个接收状态（课件第 16 张）。

### 4.5 计算树：NFA 在输入 10010 上的执行

**演示**：那具体执行起来是什么样子呢？老师用这个 NFA 在输入 $10010$ 上演示。

$q_0$ 可以转移到 $q_1$，也可以转移到 $q_3$（这是 $\epsilon$-转移，不用读字符）。然后读到 1 的时候：如果是在 $q_3$，$q_3$ 又可以转移到 $q_3$（自环）；如果是在 $q_1$，可以留在 $q_1$，也可以转移到 $q_2$。如果读到 0：在 $q_2$ 上面就是一个死状态了。

把它一层一层展开，就得到下面这样一棵计算树——每一层对应多读一个字符，同一层里的每一项是“当前可能停留在的状态”，最开始的 $q_0$ 分出两个分支，来自那两条 $\varepsilon$-箭头：

- 第 0 层（什么都没读）：由 $q_0$ 出发，可能停在 $q_1$，也可能停在 $q_3$。
- 读完第 1 个字符 $1$：从 $q_1$ 出发，可能留在 $q_1$，也可能到 $q_2$；从 $q_3$ 出发只能留在 $q_3$。所以这一层是 $q_1$、$q_2$、$q_3$。
- 读完第 2 个字符 $0$：$q_1$ 留在 $q_1$；$q_2$ 读到 $0$ 之后没有出路，这一支到这里就死掉了；$q_3$ 留在 $q_3$，也可以到 $q_4$。所以这一层是 $q_1$、$q_3$、$q_4$。
- 读完第 3 个字符 $0$：$q_1$ 留在 $q_1$；$q_3$ 留在 $q_3$；$q_4$ 只对 $1$ 有转移，读到 $0$ 的这一支也死掉。所以这一层是 $q_1$、$q_3$、$q_4$。
- 读完第 4 个字符 $1$：$q_1$ 留在 $q_1$，也可以到 $q_2$；$q_3$ 留在 $q_3$；$q_4$ 读到 $1$ 到达 $q_5$。所以这一层是 $q_1$、$q_2$、$q_3$、$q_5$。
- 读完第 5 个字符 $0$（最后一个字符）：$q_1$ 留在 $q_1$；$q_2$ 读到 $0$ 之后死掉；$q_3$ 留在 $q_3$，也可以到 $q_4$；$q_5$ 在 $0,1$ 上都有自环，所以留在 $q_5$。所以最后一层是 $q_1$、$q_3$、$q_4$、$q_5$。

然后我们看最后一层（读完所有字符之后）的这些叶子节点：只要其中有任意一个接收状态，这个自动机就接收这个输入——这里 $q_5$ 就是接收状态，所以输入 $10010$ 被接收。

就是说，只要有一条计算路径导致接收，那么这个机器就接收。所以 NFA 算起来不像 DFA 那样只有唯一一条路径，而是一棵不断分叉的树：确定性计算是一条路径，非确定性计算是一棵计算树，而接收只看这棵树里有没有某个叶子落在接收状态上。

## 五、NFA 的形式定义与接受 [01:11:06–01:17:46]

### 5.1 幂集 P(Q)

我们现在已经知道什么是有限（非确定）自动机（NFA）了。我们总是从一些例子开始，然后我们去严格地定义它。

**定义**：首先我们定义一个概念叫**幂集**（power set）。就是 $Q$ 是个集合，它的 power set 是什么呢？是 $P(Q)$，$P(Q)$ 就是它所有子集构成的集合
$$P(Q)=\{\,S: S\subseteq Q\,\}.$$

**例子**：

- 如果 $Q=\{1\}$，那 $P(Q)=\{\varnothing,\{1\}\}$，有两个元素；
- 如果 $Q=\{1,2\}$，那 $P(Q)$ 就有四个元素：$\varnothing$、$\{1\}$、$\{2\}$、$\{1,2\}$；
- 一般的，如果这个 $Q$ 有 $n$ 个元素，那 $P(Q)$ 就有 $2^n$ 个元素（构成的集合）。

为什么呢？因为对于每个元素我们可以取或者不取。

**例子**：当 $Q=\{q_0,q_1,q_2\}$ 时，$n=3$，所以幂集里一共有 $2^3=8$ 个元素，它们就是全部八个子集：
$$P(\{q_0,q_1,q_2\})=\{\varnothing,\ \{q_0\},\ \{q_1\},\ \{q_2\},\ \{q_0,q_1\},\ \{q_0,q_2\},\ \{q_1,q_2\},\ \{q_0,q_1,q_2\}\}.$$

### 5.2 NFA 的形式定义

**定义**：所以 NFA 是什么呢？依然是一个五元组
$$N=(Q,\Sigma,\delta,q_0,F),$$
其中：

1. $Q$ 是一个有限的状态构成的集合；
2. $\Sigma$ 是字母表，是一个有限的字母表；
3. $\delta:Q\times\Sigma_\epsilon\to P(Q)$——这个唯一的区别在这里。$\Sigma_\epsilon$ 是什么呢？就是 $\Sigma$ 并上 $\{\epsilon\}$：$\Sigma_\epsilon=\Sigma\cup\{\epsilon\}$。因为我们允许这种空转移，我们允许那个 $\epsilon$-箭头，所以我们加入了一个新的字符。它是这个 $Q\times\Sigma_\epsilon$ 到 $P(Q)$ 的映射。之前 DFA 是到 $Q$ 的映射，这里是到 $P(Q)$ 的映射；
4. $q_0\in Q$ 是初始状态；
5. $F\subseteq Q$ 是接收状态（集）。

为什么 $\delta$ 到 $P(Q)$ 呢？因为它是不确定的，就是我们可以不确定地在那些箭头里面选一个，所以它的下一个状态是不确定的，是一个集合，所以是到 $P(Q)$ 的一个映射，不是到 $Q$ 的一个映射。这个就是唯一的区别，其他都是一样的。

老师说：“我们什么也没做，我们只是把刚刚看的这个例子、看的这些直观形式化一下。”（时间约 01:16:31–01:17:46。）

老师接着说“我们看之前的这个例子，就是以 01 为结尾的这个字符串构成的语言”，然后把这台自动机（也就是课堂练习二第 1 题那台，见 4.6）完整地形式化写了一遍：$Q=\{q_0,q_1,q_2\}$，$\Sigma=\{0,1\}$，初始状态是 $q_0$，接收状态集 $F=\{q_2\}$。它的转移函数 $\delta:Q\times\Sigma_\epsilon\to P(Q)$ 是：
$$\delta(q_0,0)=\{q_0,q_1\},\quad \delta(q_0,1)=\{q_0\},\quad \delta(q_0,\epsilon)=\varnothing,$$
$$\delta(q_1,0)=\varnothing,\quad \delta(q_1,1)=\{q_2\},\quad \delta(q_1,\epsilon)=\varnothing,$$
$$\delta(q_2,0)=\varnothing,\quad \delta(q_2,1)=\varnothing,\quad \delta(q_2,\epsilon)=\varnothing.$$
老师逐项念了这些值：“$\delta(q_0,0)$ 就是另外一个集合 $\{q_0,q_1\}$；$\delta(q_0,1)$ 的话，如果下一个字符是 1，那它只能留在 $q_0$，所以就是 $\{q_0\}$；$\epsilon$ 就是空集……$q_1$ 读到 0 就是没有这样的（转移），就是空集；然后 $q_1$ 读到 1 我们可以到 $q_2$，所以是 $\{q_2\}$。”要特别注意：这台三状态 NFA（状态 $q_0,q_1,q_2$）与 4.4 中那台六状态 NFA（状态 $q_0,\dots,q_5$，含 $\epsilon$-箭头）不是同一台机器，虽然都用 $q_0,q_1,q_2$ 这些名字，但转移关系完全不同，两边的转移表不能互相套用。

### 5.3 NFA 的接受定义

那什么叫做接收呢？对于 DFA，因为它的计算是确定的，它的计算的路径也是确定的，是一个路径。但是对于 NFA，它的这个（计算）像一棵树一样。它接收，当且仅当有一条路径、有一个路径到的那个叶子——深度为 $n$ 的这个叶子——然后叶子接收它，它就接收了。

**定义**：所以我们怎么样定义接收呢？令 $N$ 是一个 NFA，$w$ 是一个输入，我们说 $N$ **接受** $w$，当且仅当我们可以把 $w$ 写成
$$w=w_1w_2\cdots w_n,$$
其中每一个 $w_i$ 都是一个字符、或者是一个空字符串（空串 $\epsilon$），然后存在这些状态
$$r_0,r_1,\dots,r_n\in Q$$
满足：

1. $r_0=q_0$；
2. $r_i\in\delta(r_{i-1},w_i)$，对 $i=1,\dots,n$——这里不是等于，是属于 $\delta(r_{i-1},w_i)$；
3. 最后的这个最终状态 $r_n\in F$ 是一个接收状态。

也就是说，它接收这个输入 $w$，当且仅当存在这样的一个计算路径可以导致接收。所以 DFA 也是一个 NFA，就是说 DFA 是它的一个特例；NFA 是一个看似更强大的模型。

## 六、NFA 与 DFA 的等价性 [01:17:46–01:42:33]

### 6.1 NFA 与 DFA 的等价性是本节的中心结论

**定理**：NFA 和 DFA 的计算能力是等价的：
$$L\text{ 可被某个 NFA 识别}\iff L\text{ 可被某个 DFA 识别}.$$

也就是说，NFA 看似是一个更强大的自动机，但是它其实和 DFA 是等价的。反过来的方向是显然的：如果一个语言可以被 DFA 识别，那么 DFA 也是 NFA，所以它可以被一个 NFA 识别。

所以既然它们是等价的，那我们为什么引入这个新的概念？因为可以帮我们简化、或者说极大地简化一些证明。尽管它们计算能力是等价的，但是同样的一个语言，如果我们用 NFA 去识别它，很可能这个状态数就很少。等价性证明的要点是：NFA 在某一时刻可能同时处在好几个状态里，因为它的转移是不确定的；所以我们在每一步就去跟踪“这个 NFA 当前所有可能处于的状态构成的集合”——这样一个集合就成为新 DFA 的一个状态，也就是说，新 DFA 的状态是 NFA 状态集合的子集，是 $P(Q)$ 中的一个元素。这就是“每个 NFA 都有一个与之等价的 DFA”这句话的意思。

### 6.2 等价性证明的想法：记录所有可能的状态（BFS）

那我们怎么样证明这个结论呢？想法就是一句话：就是说你有一个 NFA，然后我们从 $q_0$ 出发，我们在 $q_0$ 的时候可以做一些 $\epsilon$-这种转移，比如说我们可以同时处于 $q_0$、$q_1$、$q_2$ 一些状态，我们就记录所有可能的状态。

我们就记录，比如说第零步我们所有可能的状态是一个集合；我们比如说把这些状态用一个颜色标记，红色标记。然后下一步就是我们读了一个字符之后，我们所有可能达到的状态就是 $q_0$ 触发达到的、$q_1$ 触发达到的、$q_2$ 触发达到的——就是我们用一个集合标记那些所有可能达到的状态。最后我们得到了一个集合，就是读完最后一个字符（之后）那些所有可能达到的状态；如果里面包含一个接收状态，我们就接收。

这就好比我们在这个 NFA 上去跑一次那个 BFS、宽度搜索。（老师说成“DFS 宽度搜索”，按上下文应为**广度优先搜索**（Breadth-First Search, BFS）——即逐层记录所有可能状态的集合；ASR 把 BFS 记为“DFS/宽松”。）

本质上就是把这个 NFA 转换成了 DFA，只是状态数变成了一个幂集：本来如果是有 $N$ 个状态，现在就是 $2^N$ 个状态。就是我们把所有的这些子集、所有的（状态）集合——$2^N$ 个集合——变成一个状态，然后在集合之间进行转移。这个就是证明。

这套“读入一个字符就把所有可能状态的集合一步步算出来”的跟踪过程，在输入 $10010$ 上会得到一个固定的状态集合序列：什么都没读之前是 $\{q_0,q_1,q_3\}$（$q_0$ 的 $\varepsilon$-闭包）；读完 $1$ 之后是 $\{q_1,q_2,q_3\}$（$q_0$ 没有读到字符的转移，这一支就此消失）；读完 $10$ 之后是 $\{q_1,q_3,q_4\}$；读完 $100$ 之后还是 $\{q_1,q_3,q_4\}$；读完 $1001$ 之后是 $\{q_1,q_2,q_3,q_5\}$；读完 $10010$ 之后是 $\{q_1,q_3,q_4,q_5\}$。最后这个集合里含有接收状态 $q_5$，所以接收。这正是 6.3 中要逐步算的那一串集合。

### 6.3 例子：跟踪 NFA 在 10010 上的状态集合（BFS 模拟）

**例题**：用“记录所有可能状态”的方法模拟 4.4 中那台 NFA 在输入 $10010$ 上的执行。

**题目**：设该 NFA 的状态为 $q_0,\dots,q_5$，起点 $q_0$，接收状态为 $q_2,q_5$。它的转移关系是：$q_0$ 只有两条 $\varepsilon$-箭头（分别到 $q_1$、$q_3$），对 $0$、$1$ 都没有转移；$q_1$ 在 $0,1$ 上自环，读到 $1$ 时还可以到 $q_2$；$q_2$ 是接收状态、没有出边；$q_3$ 在 $0,1$ 上自环，读到 $0$ 时还可以到 $q_4$；$q_4$ 只对 $1$ 有转移（到 $q_5$）；$q_5$ 是接收状态并在 $0,1$ 上自环。输入字符串为 $10010$，逐步给出每一步可能处于的状态集合，并判断是否接受。

**解答**：以下是老师的逐步模拟。

1. **什么都没读**（第 0 步）：可能处于 $q_0$、$q_1$ 或者 $q_3$——因为有这个 $\epsilon$-转移，一开始我们就可能处于这三个状态中的一个，具体哪一个不知道，但是我们记录下所有的可能性，即 $R_0=E(\{q_0\})=\{q_0,q_1,q_3\}$。老师用横线表示上一步的状态集合。
2. **读完第 1 个字符 1**：$q_0$ 它“出不去”——$q_0$ 只有两条 $\varepsilon$-箭头，对 $0$、$1$ 都没有转移，所以从 $q_0$ 出发的这一支读完第一个字符就走不下去了（老师原话：“$q_0$ 它出不去，出不去就不管了”）；$q_1$ 它可能到 $q_1$，也可能到 $q_2$；$q_3$ 读到 1 还是停留在自己。所以这一步可能处于 $q_1$、$q_2$、$q_3$，即 $R_1=\{q_1,q_2,q_3\}$。
3. **再读一个 0**：$q_1$ 停在自身；$q_2$ 读到 0 就没有后续状态了，即死状态；$q_3$ 读到 0 还是自身，同时 $q_3$ 读到 0 还可以到 $q_4$。所以读完两个字符之后，$R_2=\{q_1,q_3,q_4\}$。
4. **再读一个 0**：$q_1$ 还是在自身；$q_3$ 还是 $q_3$；$q_4$ 读到 0 没有后续（$q_4$ 只对 1 有转移）。所以读了三个字符之后，$R_3=\{q_1,q_3,q_4\}$。
5. **再读一个 1**：从 $q_1$ 可能到 $q_2$，也可能停留在 $q_1$；$q_3$ 读到 1 停留在 $q_3$；$q_4$ 读了一个 1 之后到 $q_5$。所以读完这个 1 之后，$R_4=\{q_1,q_2,q_3,q_5\}$。
6. **最后读一个 0**：$q_1$ 还是在 $q_1$；$q_2$ 读到 0 就没有了；$q_3$ 还是 $q_3$，或者到 $q_4$；如果是在 $q_5$ 的话还是停留在 $q_5$（$q_5$ 在 $0,1$ 上自环）。所以最后读完所有的字符之后，$R_5=\{q_1,q_3,q_4,q_5\}$；因为 $q_5$ 是一个接收状态，所以是接收。

**结果与点评**：老师由此说明，这样的逐步跟踪本质上就是在这个 NFA 上跑一次 BFS（老师说成“DFS、宽度搜索”）：刚刚我们就用这个 BFS、用一个宽度搜索的算法去模拟了这个 NFA 的执行。大家也不难看出，我们可以把刚刚的这个模拟转换成一个 DFA，用这个幂集的方式。

> **老师强调**：所以 John Tate 不是有一句名言吗——Think geometrically, prove algebraically（想的时候用几何，证明的时候用代数）。就是我们想的时候总是用图，我们总是画图、看一些例子；那我们证明的话，我们总是去形式化地证明它。

### 6.4 NFA→DFA 等价性证明：ε-闭包与子集构造

令这个 $N$ 是一个 NFA，是这样的一个五元组 $(Q,\Sigma,\delta,q_0,F)$。我们构造一个更大的 DFA，状态数可能从这个 $|Q|$ 个变成了 $2^{|Q|}$ 个。

**定义**：首先我们定义 $\epsilon$-闭包（$\epsilon$-closure）。我们为了处理这种空转移，定义什么呢？就是如果 $R$ 是一个状态集（$R\subseteq Q$），我们定义
$$E(R)=\{\,q\in Q: q\text{ 可以从 } R \text{ 出发，经过零次或者任意多次 } \epsilon\text{-转移达到}\,\}.$$
因为我们要处理 $\epsilon$-转移，因为 $\epsilon$-转移是免费的。也就是说 $E(R)$ 就是那些经过或者不经过 $\epsilon$-转移能够达到的状态的集合。

**算法**：子集构造（subset construction）。构造 DFA $M=(Q',\Sigma,\delta',q_0',F')$ 如下：

1. $Q'=P(Q)$，就是这个幂集；
2. 它的初始状态 $q_0'=E(\{q_0\})$，就是 $q_0$ 构成的这个闭包——我们可以从 $q_0$ 出发，也可以从那些通过 $\epsilon$-转移从 $q_0$ 达到的状态出发，所以就是 $\epsilon$-闭包；
3. 对每个 $R\in Q'$ 和 $a\in\Sigma$，定义
$$\delta'(R,a)=\bigcup_{r\in R}E\bigl(\delta(r,a)\bigr)=\{\,q\in Q: q\in E(\delta(r,a))\text{ 对某个 } r\in R\,\}.$$
关键是怎么定义转移：我们是从一个状态集转移到另外一个状态集。那怎么转移过去的呢？就是对这个状态集里面的每一个 $r$ 我们都做一次 $\delta$ 转移，转移完了之后我们继续做 $\epsilon$-闭包——因为转移完了之后我们可以进行 $\epsilon$-转移——然后把这所有的并起来。
4. $F'=\{\,R\in Q': R\cap F\ne\varnothing\,\}$，就是所有（这样的）集合状态 $R$ 而 $R$ 加上 $F$ 不等于空，就是只要包含一个接收状态就可以了。

如果你仔细想一想，其实这个还是挺直观的，就是（它）就是我们刚刚做的那些事情。这四步做完之后，剩下的就是证明 $L(M)=L(N)$，而这个等式的证明用相互包含来做，也就是 6.5 中给出的两个方向。

### 6.5 等价性的严格证明：两个方向的包含

如果需要严格的证明一下，证明一下这个 DFA 它的语言 $L(M)=L(N)$，我们可以用这个相互包含：就是我们证明两个方向，就是 $L(N)$ 是 $L(M)$ 的子集，然后我们再证明 $L(M)$ 是 $L(N)$ 的子集，互为子集，然后我们就证明它们这两个自动机接收的语言是相等的。

**证明**（$L(N)\subseteq L(M)$）：我们要证明如果 $w$ 是属于 $L(N)$ 的，就是 $w$ 可以被那个非确定自动机识别，那么我们证明就是说 $w$ 可以被确定的有限自动机接收。令 $w$ 是一个长度为 $n$ 的字符串，记为 $w=w_1w_2\cdots w_n$（每个 $w_i\in\Sigma$）。因为它属于 $L(N)$，那就说明存在一组状态序列
$$q_0^{(1)},\dots,q_0^{(\ell_0)},\ q_1^{(1)},\dots,q_1^{(\ell_1)},\ \dots,\ q_n^{(1)},\dots,q_n^{(\ell_n)},$$
其中 $\ell_0,\dots,\ell_n\ge0$，使得每个分块内部相邻的状态由 $\epsilon$-箭头连接，并且对每个 $i=1,\dots,n$ 有 $q_{i-1}^{(\ell_{i-1})}\xrightarrow{w_i}q_i$。（为什么中间差了这么多呢？因为可能会做 $\ell_0$ 次 $\epsilon$-转移——它可以做零次或者任意多次的 $\epsilon$-转移；所以我们把它就是插入 $\ell_0$ 个 $\epsilon$-转移进来，然后 $q_1^{(1)}\cdots q_1^{(\ell_1)}$ 再插入 $\ell_1$ 个 $\epsilon$-转移，……然后我们再插入 $\ell_n$ 个 $\epsilon$-转移。）

令
$$R_0=E(\{q_0\}),\qquad R_i=\delta'(R_{i-1},w_i)\quad(i=1,\dots,n).$$
我们要证明的 Claim 是：$q_i^{(1)},\dots,q_i^{(\ell_i)}\in R_i$。我们用数学归纳法对 $i$ 进行归纳。

- **基础情形** $i=0$：$q_0^{(1)}$ 一直到 $q_0^{(\ell_0)}$ 都属于 $R_0$。这正是 $\epsilon$-闭包的定义——我们闭包的定义就是（从 $q_0$）可以经过 $\epsilon$ 这种箭头达到的那些（状态）。所以 base case 是显然的。
- **归纳步骤**：假设对于 $i-1$ 成立，我们证 $i$。我们要证明 $q_i^{(1)}\in R_i$，从而由 $E(\cdot)$ 的定义可知 $q_i^{(1)},\dots,q_i^{(\ell_i)}\in R_i$。
  - 如果 $\ell_{i-1}=0$，即在这一步没有进行 $\epsilon$-转移，那么 $q_i\in\delta(q_{i-1},w_i)$；因为 $q_{i-1}\in R_{i-1}$，所以 $q_i\in R_i=\bigcup_{r\in R_{i-1}}E(\delta(r,w_i))$。
  - 如果 $\ell_{i-1}>0$，即在上一步进行了 $\epsilon$-转移，那么 $q_i\in\delta\bigl(q_{i-1}^{(\ell_{i-1})},w_i\bigr)$；因为 $q_{i-1}^{(\ell_{i-1})}\in R_{i-1}$（它在那个 $\epsilon$-闭包里面），所以我们有 $q_i\in R_i$。

所以通过数学归纳法，我们就可以论证上面的这个 claim 对于 $i$ 从 $0$ 到 $n$ 都是成立的。由此可以得到：$R_0,R_1,\dots,R_n$ 正是 $M$ 在输入 $w_1w_2\cdots w_n$ 上依次经过的一个合法的状态序列，并且 $R_n$ 是一个接收状态——为什么 $R_n$ 是接收状态呢？因为 $R_n$ 包含 $q_n$，而 $q_n$ 是一个接收状态，所以 $R_n\cap F\ne\varnothing$，按 $F'$ 的定义 $R_n$ 就是一个接收状态。这样就证明了其中一个方向。

**证明**（$L(M)\subseteq L(N)$）：另外一个方向也是类似的。就是说我们要证明 $L(M)$ 是 $L(N)$ 的子集：$w$ 是被 $L(M)$ 接收的，即这个字符串被这个 DFA 接收，然后我们要证明它被 NFA 也接收。

它既然被 DFA 接收，那么就存在这样一个唯一的**状态转移序列**，记为 $R_0,R_1,\dots,R_n$，其中 $R_0=E(\{q_0\})$，$R_i=\delta'(R_{i-1},w_i)$（因为它（DFA）是确定的）。因为 $R_n\in F'$ 是一个接收状态，所以这个接收状态（集合）里面肯定含有某个状态是接收的，比如说记为 $q_{\text{accept}}$。

因为 $q_{\text{accept}}$ 在 $R_n$ 里面，所以我们考虑它的上一步：它的上一步肯定存在另外一个状态 $r$，即为从 $r$ 转移到 $q_{\text{accept}}$，中间可能经过了若干步的 $\epsilon$-转移。那我们就令 $q_n=r$，然后令 $\ell_n$ 是（这段）转移的 $\epsilon$-转移的次数，所以我们就得到了这样的一个序列 $q_n^{(1)},\dots,q_n^{(\ell_n)}$，然后最后一个状态就是一个接收状态。然后我们就重复同样的步骤，倒着做，就是从 $n-1$ 一直做到零：我们刚刚是找到了这个状态 $q_n$，然后我们再往回倒着推，就是我们再去找 $q_{n-1}$，然后从 $q_{n-1}$ 到 $q_n$ 中间也是经过了 $\ell_{n-1}$ 步的 $\epsilon$-转移。然后我们把这些状态全部找到，找到之后我们就得到了一个完整的 NFA 的状态转移序列，然后我们就可以下结论说这个 $w$ 被 NFA 接收。

就是这样的一个证明。把两个方向拼起来看，这个 NFA 在输入 $w_1w_2\cdots w_n$ 上的那条接收路径可以完整地写成
$$q_0\xrightarrow{\epsilon^*}p_0\xrightarrow{w_1}s_1\xrightarrow{\epsilon^*}p_1\xrightarrow{w_2}s_2\xrightarrow{\epsilon^*}p_2\cdots\xrightarrow{w_n}s_n\xrightarrow{\epsilon^*}p_n\in F,$$
其中 $\xrightarrow{\epsilon^*}$ 表示“零步或多步 $\epsilon$-箭头”，$\xrightarrow{w_i}$ 表示读入字符 $w_i$ 的那一步；也就是说，每读一个字符之前和之后都可以任意走若干步 $\epsilon$-箭头，最后落在接收状态集合 $F$ 里。

老师在这个方向里发现自己记号冲突，说：“$R_0$ 的话就是 $R(q_0)$，那 $R_i$ 的话——这是一个糟糕的记号，这个 $R$ 用过一次了，老师要换一下，对不起，这是 $\ell_i$，那就是这个笔误，这个是 $E$，这是个笔误，$E$ 是那个 $\epsilon$-闭包。”
> **老师强调**：老师前一天把这个（证明）丢给 AI，说“你帮我整一下、帮我写一下”，写完之后发现不太容易理解——有时候 AI 写的东西不是很容易理解，看着特别费劲，所以有时候就会重写一下。以前比如说数学工作者，他们最大的认可就是把一个结论给证明出来，证明出比如费马大定理；那现在机器你可以去烧 token，那个算力越来越强，又善于推理，也就是机器证出来了、机器给了一个几百页的证明，但是发现很难理解。所以现在能够去理解机器的证明就变得特别重要：就是一个证明能不能帮助我们人类去理解它、能够吸收它，对于解决其他问题有帮助，这很重要。

## 七、子集构造实例与连接、Kleene 星的闭包性 [01:52:02–02:02:14]

### 7.1 NFA 到 DFA 的子集构造实例

**例题**：把识别“以 $11$ 结尾的 01 串”的 NFA 转换成 DFA。

**题目**：给定一台 NFA：状态 $q_0,q_1,q_2$，起点 $q_0$，接收状态 $q_2$；$q_0$ 在 $0,1$ 上自环，$q_0\xrightarrow{1}q_1$，$q_1\xrightarrow{1}q_2$，$q_2$ 是接收状态、没有出边。请用子集构造把它转成 DFA。

**解答**：

1. 这个 NFA 可以先用一张表把它的转移函数列出来（表中的星号代表它是一个接收状态）：$\delta(q_0,0)=\{q_0\}$、$\delta(q_0,1)=\{q_0,q_1\}$、$\delta(q_1,0)=\varnothing$、$\delta(q_1,1)=\{q_2\}$、$\delta(q_2,0)=\varnothing$、$\delta(q_2,1)=\varnothing$。
2. 那我们进行展开：$q_0$ 的话它读到 0 是 $\{q_0\}$；如果是一的话它可以是 $q_0$ 或者 $q_1$，所以是 $\{q_0,q_1\}$。
3. 然后我们这次再做一次 BFS：我们再从 $\{q_0,q_1\}$ 开始：$\{q_0,q_1\}$ 如果是 0 的话，它回到 $\{q_0\}$；如果是一的话就是 $\{q_0,q_1,q_2\}$。然后我们再对 $\{q_0,q_1,q_2\}$ 再扩展展开一次：读到 0 是 $\{q_0\}$，读到 1 还是 $\{q_0,q_1,q_2\}$。
4. 所以我们最后并没有遍历所有的八个状态，我们只需要用三个状态就可以了：$\{q_0\}$、$\{q_0,q_1\}$、$\{q_0,q_1,q_2\}$。理论上理论上有可能会出现 $2^n$（这里 $n=3$，即 $2^3=8$）个不同的状态，但事实上我们做一次 BFS 之后发现只用了三个状态——因为从 $\{q_0\}$ 出发逐层展开时，只有这三个集合是真正可达的，其余五个集合都不会被访问到。
5. 那我们就把这三个状态之间的转移列出来：$\{q_0\}\xrightarrow{0}\{q_0\}$、$\{q_0\}\xrightarrow{1}\{q_0,q_1\}$、$\{q_0,q_1\}\xrightarrow{0}\{q_0\}$、$\{q_0,q_1\}\xrightarrow{1}\{q_0,q_1,q_2\}$、$\{q_0,q_1,q_2\}\xrightarrow{0}\{q_0\}$、$\{q_0,q_1,q_2\}\xrightarrow{1}\{q_0,q_1,q_2\}$。写成转移表就是：

| 子集状态（DFA 状态） | 读入 $0$ | 读入 $1$ |
|---|---|---|
| $\{q_0\}$ | $\{q_0\}$ | $\{q_0,q_1\}$ |
| $\{q_0,q_1\}$ | $\{q_0\}$ | $\{q_0,q_1,q_2\}$ |
| $\{q_0,q_1,q_2\}$ | $\{q_0\}$ | $\{q_0,q_1,q_2\}$ |

**结果与点评**：这里就是一个 DFA，因为它的转移是唯一的，因为它是从集合到集合的转移（不再是不确定的）。任何包含 $q_2$ 的 DFA 状态都成为接收状态，所以接收状态是 $\{q_0,q_1,q_2\}$。

> **原文待核实**：老师引入这个例子时说这台 NFA“识别最后是以（这个一）为结尾的（零一）串”（时间约 01:53:37–01:53:43），ASR 表述不清；按这台自动机的构造（$q_0$ 在 $0,1$ 上自环、$q_0\xrightarrow{1}q_1$、$q_1\xrightarrow{1}q_2$、接收状态 $q_2$）与其子集构造的结果（只有 $\{q_0,q_1,q_2\}$ 是接收状态，它对应“已经连续读到了 $11$”），这台 NFA 识别的应是**以 $11$ 结尾**的字符串，故题目按此改写，老师的原话并存待核实。

### 7.2 为什么有了 DFA 还需要 NFA

我们为什么还需要 NFA 这个概念呢？既然它们计算能力都等价。老师给出两个原因：

1. **状态数可能更少**：虽然它们的计算能力等价，但是识别同样的语言的 NFA 状态数可能远远小于 DFA。如果老师没记错的话，这里面也是有一些公开问题：就是说（给定一个）NFA、（给定）它识别的语言，然后（构造识别该语言的 DFA），它这个状态数能有多小——这些里面还是有一些 gap 什么的，但是这些问题也不会被认为是非常主要的一些问题。
2. **可以简化证明**：另一方面，主要是我们这门课上它可以帮我们简化一些证明。

刚才这个子集构造的例子也可以说是一个**算法式的证明**：就是我们给出了这样一个算法，把 NFA 转换成 DFA。

数学里面证明大体上有两类：一类是**存在性的**，一类是**构造性的**。那什么是构造呢？构造就是给一个算法。那什么是算法呢？算法就是一个图灵机。

所以我们回到之前的这个动机：我们讲了这么多 NFA，其实我们为什么讲它呢？我们是要证明连接（的闭包性）。有了 NFA 和“NFA 与 DFA 等价”这个结论之后，连接的闭包性和 Kleene 星的闭包性都可以用同样的办法证明：给 NFA 加几条 $\epsilon$-箭头。

### 7.3 连接的闭包性：用 ε-箭头把两台机器连起来

**定理**：如果 $L_1,L_2$ 是正则语言，那么它们的连接 $L_1\circ L_2$ 也是正则的。

**证明**：证明的办法就是把两台机器连起来：让第一台机器先跑，当它跑到某个接收状态时，不需要再读任何字符（也就是走一条 $\epsilon$-箭头），直接进入第二台机器的初始状态，接着让第二台机器继续跑剩下的输入。也就是说，从第一台机器的每一个接收状态都引一条 $\epsilon$-箭头，连到第二台机器的初始状态；其余部分都不动。这样，一个字符串被新机器接收，就等价于它能在某个位置被切成两段，前一段被第一台机器接收、后一段被第二台机器接收——也就是它属于 $L_1\circ L_2$。证明结束。

因为我们有了这个新的概念 NFA、非确定有限自动机，而且我们证明了它和 DFA 的等价性，所以我们可以就假设 $N_1$ 识别 $L_1$、$N_2$ 识别 $L_2$，这两个是 DFA 或者 NFA 都可以。我们构造一个大的 NFA 非确定的有限自动机，怎么构造呢？就加一些 $\epsilon$-箭头：就是把所有的 $N_1$ 的接收状态连一个 $\epsilon$-箭头，连到 $N_2$ 的初始状态。证明结束。

就是说令 $N_1=(Q_1,\Sigma,\delta_1,q_1,F_1)$ 是一个识别 $L_1$ 的自动机，$N_2=(Q_2,\Sigma,\delta_2,q_2,F_2)$ 是识别 $L_2$ 的自动机。我们构造一个 NFA $N=(Q,\Sigma,\delta,q_1,F_2)$，它把这两个给连起来：

1. $Q=Q_1\cup Q_2$，也就是把两台机器的状态并在一起；

3. 接收状态就是第二个机器的接收状态：$F_2$；
4. 然后这一堆定义就是把它给连起来，其他都不变。完整写出来就是

### 7.4 Kleene 星的闭包性

**定理**：如果 $L$ 是正则语言，那么 $L^*$ 也是正则的。

2. $F'=F\cup\{q_{\text{new}}\}$；

5. **交**（Intersection）：$L_1\cap L_2$；

## 九、泵引理：陈述、证明与应用 [02:15:21–02:28:12]

### 9.1 泵引理：陈述

我们知道几乎所有的语言都是不正则的，那我们怎么样证明一个具体的语言是不正则的呢？这里用到了一个工具，叫做 pumping lemma，就是水泵、泵（pump）。前面 8.2 的计数论证只告诉我们“不正则的语言非常多”，但没有告诉我们某一个指定的语言是不是正则；泵引理就是用来证明“某个具体语言不正则”的工具。

**引理**：**泵引理**（Pumping Lemma）。如果 $L$ 是一个正则语言，那么存在一个整数 $p\in\mathbb{N}$，使得对于任意字符串 $s\in L$ 且 $|s|\ge p$，我们都可以把 $s$ 写成
$$s=xyz,\qquad x,y,z\in\Sigma^*,$$
并且满足三条性质：

1. 对所有的 $i\ge0$，$xy^iz\in L$；
2. $|y|>0$；
3. $|xy|\le p$。

- $p$ 就是当这个字符串足够长的时候（的那个阈值），足够长是多长呢？大于等于 $p$ 的时候。
- 我们可以对任意的其中一个足够长的字符串，我们都可以把它写成三部分 $xyz$；然后你可以对 $y$ 进行 pump，就是去水泵。
- 什么（叫）水泵？就是说你可以不停地重复它：就是 $xyz$ 或者 $xyyz$、$xyyyz$，你可以把它 pump 任意多次；任意多次之后它还在这个语言里面。
- 其他的两个性质就是说：中间这个 $y$ 的长度大于 0——如果长度是零的话，去 pump 它也没什么意义；还有一个性质就是 $xy$ 的长度不是太长，就是小于等于 $p$。

这个引理说的就是这样的一件事情：如果这个语言是正则的，并且这个字符串足够长，那么你可以把它分成三段 $xyz$，然后你可以任意次地去重复 $y$，你这一次的重复之后还在这个语言里面。但是对于很多语言它做不到，所以是矛盾、是一个 contradiction。所以我们一般都是用反证法。

> **老师强调**：就假设这个语言是正则的，那我们就可以 pump 它；但是我们发现最后我们找了一个足够长的字符串，发现没有办法 pump，所以它不是正则的。

### 9.2 泵引理的证明

那怎么证明这个引理呢？一句话，同学们，一句话：就是说你看这个是一个有限状态自动机，对吧？你肯定是我们肯定是访问了一些状态，然后最后回到一个接收状态，对吧？就是当这个字符串足够长的时候——当这个字符串的长度它大于等于这个状态数的时候——那肯定会产生重复，对不对？就是说我们肯定会重复地访问了这个状态。我们可能是先读了前面这一段 $x$，然后在这里绕了一圈，然后又回到这个（状态），然后再读 $z$、回到这，对吧？既然能绕一圈，我们就可以不停地绕：这个你可以绕一圈、绕两圈、绕三圈都可以。所以你就可以 pump 它，证明结束。

**证明**：令 $M=(Q,\Sigma,\delta,q_0,F)$ 是一个识别 $L$ 的 DFA，令
$$p=|Q|.$$
令 $s=s_1s_2\cdots s_n$ 是一个长度为 $n$ 的字符串，其中 $n\ge p$。令 $r_0,r_1,\dots,r_n\in Q$ 是在输入 $s$ 上访问的状态序列，即
$$r_0=q_0,\qquad r_i=\delta(r_{i-1},s_i)\quad(1\le i\le n).$$
根据鸽笼原理：因为这个字符串的长度是 $n\ge p$，那么它访问了 $n+1$ 个状态，所以 $n+1>p$，就是鸽子的数目大于笼子的数目；所以在这个序列里面必定有一个状态会重复。

那我们就考虑**第一次的重复**——就是说我们考虑第一次的重复，就是在此之前的没有重复。假设这个状态第一次出现是 $r_i$，然后第二次出现是 $r_j$（$i<j$），然后我们把这个字符串分成三部分，把 $s$ 分成 $xyz$：从 $s_1$ 到 $s_i$ 这（是 $x$，对应）第一次出现；然后从 $s_{i+1}$ 到 $s_j$（是 $y$），就是绕圈——就是在这个状态绕了一圈；$z$ 就是从 $s_{j+1}$ 到 $s_n$。也就是
$$x=s_1\cdots s_i,\qquad y=s_{i+1}\cdots s_j,\qquad z=s_{j+1}\cdots s_n.$$

1. **$|y|\ge1$**：这个是显然的，因为 $i<j$，因为它是重复出现，它这个长度就是 $j-i$，是大于等于 1 的。
2. **$|xy|\le p$（即 $j\le p$）**：因为 $r_j$ 是第一次出现（指第一次被重复的那个状态），所以此前是没有任何重复的；所以我们可以说这个 $j$ 是小于等于 $p$ 的。（因为它是第一次重复，在这之前的状态 $r_0,\dots,r_{j-1}$ 两两不同，共有 $j$ 个不同的状态，而 $Q$ 一共只有 $p$ 个状态，所以 $j\le p$。）
3. **$xy^iz\in L$ 对所有的 $i\ge0$ 成立**：因为 $y$ 这个（部分）就是在绕圈——$r_i=r_j$，机器可以从 $r_i$ 出发读 $y$ 再回到 $r_i$；所以你可以绕零次、可以绕一次、可以绕任意多次。所以 $xy^iz$ 都是属于 $L$ 的，对于所有的 $i\ge0$ 都成立。

所以这个就是 pumping lemma（泵引理）的证明。

老师强调：“就是一行的证明、一行的证明。”（指证明的核心思想一句话可说完：状态数有限，长字符串必然重复访问状态，重复的那一段可以任意次重复。）

> **老师提示**：然后我们再看一下，就是再一次，我们叫 think（geometrically）、叫 geometrically 我们画一张图，对吧？我们 prove（algebraically）。中间用了一个什么原理呢？叫鸽笼原理。

这里用的就是**鸽笼原理**（pigeonhole principle）：因为我们读的长度 $|s|\ge p$，所以这次运行至少访问了 $p+1$ 个状态（包括初始状态）；而一共只有 $p$ 个状态，所以必有一个状态被访问了不止一次。（老师课上口头说的是“因为这个字符串的长度是 $p$，那么它肯定访问了 $p+1$ 个状态”；按证明的需要，这里应理解为 $n\ge p$，此时访问的状态数是 $n+1\ge p+1>p$，结论不变。）

鸽笼原理是什么呢？上面有几个（笼子）、有 1、2、3、4、5 个鸽子对吧——把五个鸽子放到 4 个笼子里面，一个笼子里面至少有两只或者两只以上的鸽子。你说老师这样可不可以：就是说这个笼子里没有鸽子？也可以、也可以，就有的笼子里可能没有鸽子，有的笼子里有两个、三个，对吧。但是我们的结论是什么？就是说至少有一个笼子，这个笼子里面有超过一只的鸽子。所以至少有一个状态被访问了超过一次、大于等于两次。那有些状态没被访问，对吧。

**课堂问答**：老师提出问题：那这个原理怎么证明？大家可以想一下怎么证明鸽笼原理——并评价“非常有用、非常有用”。

### 9.3 泵引理的使用方式：反证法

那我们怎么用这个 pumping lemma 呢？一般都是反证法：

1. 我们假设这个语言是正则的；
2. 由泵引理，存在一个整数 $p$ 使得那三条性质成立；
3. 然后我们找一个足够长的字符串 $s\in L$（$|s|\ge p$）；
4. 然后我们去 pump 它，结果发现被 pump 之后的不在 $L$ 里面；
5. 然后就得到了一个矛盾，所以它不是正则的。

这套用法的要点就是：先假设它是正则的，然后拿一个足够长的字符串去 pump，指出某一个 $xy^iz$ 落在了这个语言之外，从而产生矛盾。所以泵引理是一个用来**否定**正则性的工具——它只能用来证明“不正则”，不能用来证明“正则”（要证明正则性，还是得把自动机或 NFA 构造出来）。

### 9.4 例子：$\{0^n1^n\}$ 不是正则语言

**例题**：证明 $L=\{0^n1^n:n\ge0\}$ 不是正则语言。

**题目**：用泵引理证明 $L=\{0^n1^n:n\ge0\}$ 不是正则的。

**解答**：

直观上为什么呢？因为自动机它不能记忆，它只能记忆有限的这个信息，所以它没有办法记住我读了多少个 0，所以它不是正则的。

**证明**（用泵引理）：

1. 我们假设 $L$ 是正则的。
2. 那么根据 pumping lemma，就是存在一个整数 $p$，使得那三个条件成立。
3. 那我们令这个 $s$ 等于多少呢？我们让 $s$ 足够长就可以了，就是 $s=0^p1^p$（$p$ 个 0 接着 $p$ 个 1）；显然 $s\in L$ 且 $|s|=2p\ge p$。
4. 根据泵引理，我们可以把这个字符串分成三段，就是 $xyz$。
5. 因为 $|xy|\le p$，所以 $xy$ 肯定（全部）是 0——就是 $x$ 是一些 0、$y$ 是一些 0（$y=0^k$，$k\ge1$）。
6. 然后我们去 pump 这个 $y$：我们去重复这个 $y$，我们重复 $y$ 就会使 0 的个数变多，0 的个数变多超过了一的个数（例如取 $i=2$，$xy^2z=0^{p+k}1^p$，其中 $k\ge1$），那么这个字符串就不在这个语言里面（$0^{p+k}1^p\notin L$，因为 $0$ 比 $1$ 多）。
7. 所以就产生矛盾了。

**结果与点评**：所以这样就证明了这个语言不是正则的。老师强调，这套“假设正则 → 取长串 → pump → 矛盾”的推理是可以套用到所有非正则性证明上的固定套路（见 9.3）。

### 9.5 课堂练习三：六道非正则性证明题

**例题**：用泵引理证明下列语言不是正则的。

**题目**：用泵引理证明下面每一个语言都不是正则的（花五分钟，写一个大概的思路就可以了：就是你去选一个什么样的字符串去 pump 它）。

1. $\{0^n1^n:n\ge0\}$；
2. $\{\,w: w\text{ 中 0 的个数和 1 的个数相等}\,\}$；
3. $\{ww: w\in\{0,1\}^*\,\}$；
4. 回文（palindromes）：$L=\{\,w\in\{0,1\}^*: w^R=w\,\}$；
5. $\{0^n1^m: n>m\}$；
6. $\{0^n: n\text{ 是完全平方数}\,\}$。

**解答**：下面是老师抽到的同学的回答、逐题点评与完整证明。

1. **第一题（$\{0^n1^n\}$）**：取 $s=0^p1^p$，因为 $y$ 肯定是 0（由 $|xy|\le p$ 保证），$y$ 将重复多次，0 会比 1 多，所以产生矛盾。老师评价：“非常好啊非常好。”

   完整写法：假设 $L=\{0^n1^n:n\ge0\}$ 是正则的，泵引理给出 $p$。取 $s=0^p1^p\in L$，$|s|=2p\ge p$。由 $|xy|\le p$ 知 $xy$ 全部落在开头那段 0 里，即 $x=0^a$、$y=0^k$、$z=0^{p-a-k}1^p$，其中 $k=|y|\ge1$。取 $i=2$，得 $xy^2z=0^{p+k}1^p$：0 的个数比 1 多，所以 $xy^2z\notin L$，与“对一切 $i\ge0$ 都有 $xy^iz\in L$”矛盾。
2. **第二题（0 的个数和 1 的个数相等）**：同学取的是比如说 $0^p1^p$，然后（因为 $|xy|\le p$）$y$ 肯定是一些 0，可以去 pump 它，导致 0 的个数变多，然后就不在这个语言里，产生矛盾。老师评价：“非常好。”

   完整写法：取同一个 $s=0^p1^p$（它也在“0、1 个数相等”这个语言里）。同上可得 $y=0^k\ (k\ge1)$，于是 $xy^2z$ 中 0 的个数变成 $p+k$、1 的个数仍是 $p$，两者不再相等，$xy^2z\notin L$，矛盾。
3. **第三题（$\{ww\}$）**：一位同学取的是这个字符串 $0^p1^p0^p1^p$；因为 $|xy|$ 的长度是小于等于 $p$，所以 $y$ 肯定是连续个 0，然后去 pump 它会产生矛盾。老师评价：“非常好。”

   完整写法：取 $s=0^p1^p0^p1^p=ww$（$w=0^p1^p$），$|s|=4p\ge p$。由 $|xy|\le p$ 得 $y=0^k\ (1\le k\le p)$，于是 $xy^2z=0^{p+k}1^p0^p1^p$。若它等于 $uu$，则 $|u|=2p+k/2$，故 $k$ 必为偶数；此时 $u$ 的前 $p+k$ 个字符全是 0，所以 $u$ 以 0 开头，而第二个 $u$ 的起点落在原串中间那段 1 里（因为 $k\ge2$ 时 $2p+k/2+1\le2p+k$），以 1 开头，两边首位不同，矛盾。所以 $xy^2z\notin L$，矛盾。（更省事的取法是 $s=0^p10^p1$：同样 $y=0^k$，$xy^2z=0^{p+k}10^p1$；若它形如 $uu$，则 $u$ 全为 0，与串中含有 1 矛盾。）
4. **第四题（回文语言）**：老师抽了同学作答，但随后即宣布下课，课堂未及点评；这里按泵引理的标准做法补出完整证明。假设 $L=\{w\in\{0,1\}^*:w^R=w\}$ 是正则的，泵引理给出 $p$。取 $s=0^p10^p\in L$（它是回文），$|s|=2p+1\ge p$。由 $|xy|\le p$ 知 $y=0^k\ (1\le k\le p)$，于是 $xy^2z=0^{p+k}10^p$：左边有 $p+k$ 个 0、右边只有 $p$ 个 0，把它倒过来不再等于自身，所以 $xy^2z\notin L$，矛盾。
5. **第五题（$\{0^n1^m:n>m\}$）**：同样补出完整证明。取 $s=0^p1^{p-1}$：这里 $n=p>p-1=m$，所以 $s\in L$，且 $|s|=2p-1\ge p$（$p\ge1$）。由 $|xy|\le p$ 知 $y=0^k\ (1\le k\le p)$。这时要取 $i=0$（把 $y$ 删掉）：$xy^0z=0^{p-k}1^{p-1}$，0 的个数变成 $p-k\le p-1$，不再大于 1 的个数，所以 $xy^0z\notin L$，矛盾。（注意这里不能向上泵：$0^{p+k}1^{p-1}$ 仍然满足 $n>m$，泵大不会产生矛盾。）
6. **第六题（$0^n$，$n$ 是完全平方数）**：同样补出完整证明。取 $s=0^{p^2}$：$p^2\ge p$ 且 $p^2$ 是完全平方数，所以 $s\in L$。由 $|xy|\le p$ 知 $y=0^k$，其中 $1\le k\le p$。取 $i=2$，得 $xy^2z=0^{p^2+k}$，而
   $$p^2<p^2+k\le p^2+p<(p+1)^2,$$
   即 $p^2+k$ 夹在两个相邻的完全平方数之间，不是完全平方数，所以 $xy^2z\notin L$，矛盾。

**结果与点评**：本次练习共六题，老师按顺序抽了六位同学分别作答，随后明确逐题点评了前三题（评价分别是“非常好啊非常好”“非常好”“非常好”），并总结“然后我们也是应该（看到）大家都是做的不错的”，紧接着即宣布下课（02:36:46–02:37:00）。因此第四至第六题课堂上只组织了作答、没有给出解答与点评。上面第 1–3 题保留了老师与同学在课堂上的原话式思路，并补上完整写法；第 4–6 题的完整证明是按泵引理的标准做法补出的（不属于课堂讲授内容，供对照使用），其中第五题要用 $i=0$ 向下泵、第六题取完全平方数长度 $p^2$，都是这类证明里的常用技巧。

> **原文待核实**：第三题同学所取的字符串，ASR 记为“是 $0^p1^p$”（时间约 02:36:24–02:36:37），但老师随后说“因为 $xy$ 的长度是小于等于 $p$，所以 $y$ 肯定是连续个 0，然后去 pump 它会产生矛盾”。对于 $\{ww\}$ 的标准取法是 $s=0^p1^p0^p1^p$，此时 $|xy|\le p$ 确实保证 $y$ 全为 0，pump 后 $0$ 的个数与 $1$ 的个数失衡、不再形如 $ww$。同学所写的原字符串细节原文待核实。

### 10.5 下课后关于 Kleene 星构造的追加讨论

宣布下课后（02:39:28–02:40:41），老师与同学继续讨论了 7.4 中 Kleene 星构造的细节：书上（的做法）是在（原有自动机上）引入一个新的节点来做（星），因为如果（直接把原来的初始状态设成接收状态）——他（原机器）如果有环的话，会引入额外的字符串，也被这个（新机器）接住。

为什么不太对呢？因为如果直接把原来的初始节点设成接受节点的话，如果这里有环，可能会导致额外的字符串被接受。然后老师（与同学）得出结论：如果想（避免）接受额外字符串的话，那干脆直接找那个通用的（构造，也就是引入新初始节点）。“有道理、有道理。”这样确实会导致（问题），等于是再加一个（状态）然后过来，就像这样（新节点通过 $\epsilon$-箭头连到原初始状态，原接收状态再通过 $\epsilon$-箭头回到新节点，新节点同时是接收状态）。

这段讨论与 7.4 的课件构造（引入新初始状态 $q_{\text{new}}$）一致，是对“为什么必须引入新的初始节点、而不能直接把原初始状态改成接收状态”的补充说明。
