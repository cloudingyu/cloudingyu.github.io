# Notebook font subsets

- `wenkai.woff2`: LXGW WenKai Mono Regular 1.510, by lxgw and the font's upstream contributors.
- `mono-regular.woff2` and `mono-bold.woff2`: Maple Mono 7.000, by subframe7536 and contributors.

These fonts are distributed under the SIL Open Font License 1.1. Copyright and license information is retained in each font's name table; the accompanying OFL files contain the full license text and upstream copyright notices.

The subsets use distinct internal family names (`CY Notebook WenKai` and `CY Notebook Mono`). Blog posts and semester notes share these fonts. They include the blog and semester note character sets and ordinary Latin, Greek and punctuation. Regenerate with `scripts/subset-notebook-fonts.py` when the content character set changes.

Upstream projects:
- https://github.com/lxgw/LxgwWenKai
- https://github.com/subframe7536/maple-font
